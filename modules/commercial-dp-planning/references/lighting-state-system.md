# Lighting State System

Create short state IDs before writing the shot table.

## State card fields

```text
ID and name
Story function
Time of day
Motivated sources
Key direction
Key/fill relationship
Background level
Color-temperature relationship
Practical-light state
Floor or lower-body treatment
Product emphasis
Transition from previous state
DMX cue or manual change
Grey-card, skin, white-wall, highlight and clean-plate requirements
```

## State design rules

- Keep skin plausible across all states.
- Express temperature through environment, contrast, lower-body reflection, wardrobe, practicals, and behavior before tinting faces.
- Specify measurable relative changes such as “background -1 stop” or “face +1/3 stop.”
- Preserve a motivated source even in stylized moments.
- Record which fixtures move, dim, recolor, or switch off.
- A solution state should not erase all contrast; it should feel more comfortable, even, or open.

## Common commercial patterns

### Bright cold day
Neutral-to-cool window source, clean skin fill, low saturation, visible floor texture, no blue wash.

### Warm domestic night
Warm practical motivation, soft key near activity, slight cool separation at window or doorway, lifted shadow detail.

### Stylized flashback
Environment reduced 1.5–2 stops, directional profile light, selected practical or prop highlights, retained set outline, optional light haze.
