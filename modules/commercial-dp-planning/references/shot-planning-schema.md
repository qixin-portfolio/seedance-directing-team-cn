# Shot Planning Schema

Use one row per final shot setup.

| Field | Requirement |
|---|---|
| Sequence / original shot | Preserve editorial mapping |
| Action | Describe visible action, not dialogue only |
| Duration | Use supplied duration or mark unconfirmed |
| Camera | Assigned body and role |
| Lens / focal length | Exact focal length or practical range |
| Aperture intent | Depth-of-field target; do not fabricate exposure |
| Framing | Establishing, wide, medium, close, insert, macro |
| Movement | Push, pull, pan, whip, track, zoom, orbit, jib, handheld |
| Support | Tripod, slider, dolly, gimbal, jib, hi-hat, overhead |
| Lighting state | Numbered state ID |
| Lighting adjustment | Shot-specific flag, bounce, edge, product light |
| Filters | Diffusion, ND, CPL, clear; state when removed |
| Focus plan | Marks, motor axes, autofocus test, macro method |
| Cast / prop continuity | Position, wetness, sweat, water level, screen state |
| VFX / post | Clean plate, tracking, effect direction, screen replacement |
| Safety | Water, heat, smoke, rigging, child, animal, elderly performer |
| Confidence | Confirmed / inferred / pending test |
