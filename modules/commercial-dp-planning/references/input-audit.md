# Input Audit

## Evidence levels

| Level | Meaning | Required wording |
|---|---|---|
| Confirmed | Explicitly present in supplied script, PPM, image, schedule, or equipment list | State directly and cite the source location when available |
| Inferred | Supported by several visual or production clues | Prefix with “建议” or “推测” and explain the basis |
| Missing | Needed for a safe or accurate decision | Mark “待确认”; ask only when the missing fact blocks execution |
| Conflicting | Two supplied sources disagree | Show both versions and identify which document controls |

## Minimum input checklist

- Final script or shooting board
- Latest version number and revision date
- Tone references
- Location photographs or plan
- Art direction and practical fixtures
- Cast list and availability limits
- Confirmed camera, lenses, filters, movement, monitoring
- Shoot days and working hours
- Product UI and screen replacement plan
- VFX, smoke, water, children, animals, elderly performers

## Version discipline

Never rely on shot number alone when revisions exist. Use:

```text
sequence + shot number + action description
```

Example:

```text
Heating / 11 / daughter enters and zooms from close to wide
```
