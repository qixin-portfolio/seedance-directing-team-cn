# 资产压力测试（Stress Test）

静图通过只说明“看起来对”；压力测试回答“跑起来还对不对”。

## 推荐测试矩阵

关键角色至少覆盖实际项目会遇到的几类条件：

- 近景对白；
- 中景走动；
- 全身动作；
- 明显转头、低头或抬头；
- 微笑 / 大笑 / 紧张等会改变嘴和下颌的表演；
- 双人同框或与关键配角互动；
- 与正式场景 Plate 同时使用。

不要求机械地固定为十次；推荐 6–10 个代表性测试，重点覆盖真实生产边界。

## 人物和场景一起测试

**人物和场景一起测试**。人物图与场景 Plate 会互相拉扯；角色单独稳定，不代表进入正式场景、逆光、双人镜头或全身动作后仍稳定。

## 验收

记录：测试编号、镜头条件、通过项、失败项、失败来源、是否属于随机性。

如果同一错误在合理 Prompt 下连续重复：

1. 先检查素材职责和 Prompt；
2. 再检查角色 / 场景资产是否本身含有冲突信息；
3. 资产问题成立时**重建资产**，不要无限增加提示词。

关键资产达到预期生产条件后，标记 `PRODUCTION_APPROVED`。
