# 视觉锚点、首尾帧、关键帧、宫格与白模

## 默认：分镜图当片段内部的视觉锚点（VISUAL_ANCHOR）

**项目经验（用户 2026-11 实测，P 级，版本/平台随项目记录）**：把分镜图放进片段中段当“视觉锚点”，比当首尾帧好得多——片段开头和结尾都在运动里，不会出现首帧定格、尾帧硬停、两张图之间直接变形。所以有分镜图时，**默认用 `VISUAL_ANCHOR`**，首尾帧只用于下一节列出的少数情况。

### 锚点怎么排

| 规则 | 写法 | 参考值（12 秒片段） |
|---|---|---|
| 锚点前有引入段 | 片段从锚点之前的动作开始，用运镜“抵达”锚点构图 | 第一锚点的抵达段不早于约 1.5 秒开始（例：1.7–4.0 秒） |
| 锚点之后有出口段 | 最后一个锚点之后继续运动，结尾是交给下一片段的“接口”，不停在锚点上 | 最后一个锚点结束后至少留约 1.5 秒（例：10.5–12.0 秒） |
| 锚点之间有物理过程 | 写清从锚点 A 到锚点 B 的因果链，禁止“图 01 直接变成图 02” | 两个锚点之间至少约 3 秒过程（例：4.0–8.8 秒） |
| 锚点数量 | 一个锚点一个抵达段 | 12 秒 ≤2 个，15 秒 ≤3 个；Seedance 2.0 从严 ≤2 个 |
| 锚点是经过不是定格 | 抵达后在构图里演完这一拍（动作/台词），随后继续运动离开 | 每个抵达段约 1.7–2.3 秒 |

秒数是节奏预算，不是帧级剪辑点；按台词实际时长和项目节奏调整，但三段式（引入 → 锚点 → 过程 → 锚点 → 出口）不变。

### 每个锚点抵达段要写的四件事

1. **抵达方式**：摄影机怎样到达这个构图（例：“沿红线快速抬升，从地面特写升至微广角中景”“顺着红线快速上摇，再向右小幅环绕”）。运镜要有动机，跟着主体或线索走。
2. **忠实抵达 + 文字复述**：写“忠实抵达分镜图NN的主体关系和构图：<主体、前景、背景、占屏、朝向>”。不只靠图，把关键关系用文字再说一遍。
3. **在锚点上的戏**：这一拍的动作、表演、台词和“说话状态”（音量、语速、重音、情绪底色）。
4. **怎么离开**：下一段的第一动作就是离开锚点的理由（例：毛绒球突然滚走）。

### 锚点之间的过程段

- 用“过程完整”替代“状态切换”：写成可看见的物理链，如“红线攀爬 → 盘旋 → 绒毛生长 → 帘幕落下”，并写一句“不是突然出现”。
- 需要换机位侧时，用镜内遮挡完成（例：一名路人从镜头前完整掠过，借遮挡切到少女背后），不无故旋转摄影机。
- 主体的情绪和动作强度在过程段保持人物逻辑（例：“步伐轻盈，不是逃命”）。

### 出口段和【结束状态】

- 最后一段把主体送进下一片段的入口：身体仍在运动、摄影机仍在跟、画面留一个能接的东西（例：绒毛遮满两侧，只留一条看得见集市灯光的窄缝）。
- 单独写【结束状态】：主体位置与动作趋势、摄影机相对位置、画面里留下的接口元素。下一片段的引入段从这里继续写；需要逐帧接上时，才把上一片段实际采用素材的最后一帧当下一片段的 `START_FRAME`。
- 下一片段的声音可以在出口段提前进入（例：帘幕后的叫卖声），作为声音接口。

### 素材声明

```text
@图片1 — ROLE: VISUAL_ANCHOR（锚点1｜约1.7–4.0秒）；ADOPT：主体关系、构图、景别、机位方向、关键道具状态；IGNORE：[图中临时物件/文字]；FRAMING POLICY：片段内部抵达，不是首帧，也不是尾帧；抵达后继续运动，不定格。
@图片2 — ROLE: VISUAL_ANCHOR（锚点2｜约8.8–10.5秒）；ADOPT：……；FRAMING POLICY：片段后段抵达，不是尾帧。
@图片3 — ROLE: IDENTITY_ONLY；ADOPT：<人物A>的五官、发型与服装；IGNORE：背景和姿势。
```

提示词正文里再用自然语言各说一次（这两句对结果影响大，不省）：

```text
使用分镜图01 @图片1、分镜图02 @图片2 作为视觉参考。
分镜图01是片段中段的第一处核心视觉锚点，不是首帧。
分镜图02是后段的第二处核心视觉锚点，不是尾帧。
```

平台有自己的素材引用语法（如 `{{Mixed N}}`）时按平台写，其余规则不变。锚点图和输出用同一画幅。

### 锚点段落式提示词结构

模板见 `assets/anchor-segment-prompt-template.txt`，校验用 `python3 scripts/validate_anchor_prompt.py <文件>`（正式项目加 `--production`）。

```text
【参考资产】锚点声明 + 两句“不是首帧/不是尾帧” + 人物/道具/场景身份参考
【时长】
【整体事件】一句话写完整事件链
【0.0—a秒｜引入段标题】画面、摄影（器材/焦段/T档）、动作、声音
【a—b秒｜抵达分镜图01】抵达方式、忠实抵达+复述、表演、台词+说话状态、声音
【b—c秒｜过程段标题】……
【c—d秒｜抵达分镜图02】……
【d—总时长｜出口段标题】……
【结束状态】
【限制条件】锚点必须出现在片段内部、不设为首尾静止画面；不直接从图01变形成图02；不无原因旋转摄影机；不改变服装和关键道具外观；不生成字幕、水印或背景音乐（按项目政策）
```

正式项目照样过必过关卡：每段写器材、焦段、T 档；有戏人物写“⚠️<人物>表演（本片段）”；说话人逐字贴“<人物>声音”。

### 实测样例（用户提供，节选结构）

12 秒，女主 + 毛绒球。0–1.7 秒超低机位跟拍毛绒球穿过人群 → 1.7–4.0 秒沿红线抬升，抵达分镜图01（少女弯腰、毛绒球在前景），少女说“哎？你这儿怎么还有根线啊？” → 4.0–6.2 秒毛绒球滚走、摄影机绕到斜前方 → 6.2–8.8 秒追线穿行，路人遮挡切到背后 → 8.8–10.5 秒上摇加小幅环绕，抵达分镜图02（红线长成毛绒拱门） → 10.5–12 秒拨开帘幕，绒毛遮满画面只留窄缝，作为片段02入口。

## 首尾帧：只在这些情况用

| 用 | 场景 |
|---|---|
| `START_FRAME` | 接上一片段实际采用素材的最后一帧（需要逐帧连上时）；向后延长；产品/packshot 开场必须精确复现；复现已 APPROVED 的画面；用户明确要求首帧 |
| `END_FRAME` | 向前延长，结尾必须到达原视频首帧；产品或 logo 最终定版必须静止落版；用户明确要求尾帧 |

其他情况，分镜图一律当 `VISUAL_ANCHOR`。用首尾帧时逐张声明，不能合并为一句：

```text
@图片1作为首帧，定义开始时的构图、主体位置、姿态、道具状态、场景和镜头方向。
@图片2作为尾帧，定义结束时的构图、主体位置、姿态、道具状态、场景和镜头方向。
@图片3只用于人物身份与服装，不改变首帧和尾帧构图。
画面从@图片1自然开始，经过[连续事件]后到达@图片2。
```

首尾图使用相同画幅。首帧定义动作将起或刚起的可执行状态；尾帧定义完整终态。可以混用：`START_FRAME` 接上一片段 + 中段 `VISUAL_ANCHOR`，仍按上面的锚点排法留出过程段和出口段。

## 多关键帧

多张分镜图也优先当按顺序排列的 `VISUAL_ANCHOR`，第一张不放在 0 秒、最后一张不放在结尾：

```text
按@图片1至@图片3的顺序作为片段内部的视觉锚点，都不是首帧或尾帧。
[引入段] → 抵达@图片1：[锚点状态] → [物理过程] → 抵达@图片2：[锚点状态] → [物理过程] → 抵达@图片3：[锚点状态] → [出口段与结束状态]。
各锚点之间用连续动作完成因果过程，不直接变形；保持身份、道具、场景、光线和轴线连续。
```

关键帧控制顺序和关键状态，不等于逐帧复刻。独立图片通常比密集拼图稳定。只有延长或严格接帧时，才把第一张或最后一张改成 `START_FRAME` / `END_FRAME`。

## 宫格分镜

- 建议15格以内、线稿清楚、文字少。
- 明确读取顺序和“每格是否代表完整镜头”。
- 宫格控制镜头顺序、大致构图、景别和动作位置；不自动控制最终人物身份和美术风格。

```text
@图片1提供[N格宫格分镜]，按[左到右、上到下]读取；不采用线稿画风、文字标注和占位人物。
@图片2定义人物A；@图片3定义场景A。
镜头1：[构图、景别、动作、终态]。
镜头2：承接镜头1终态，[运镜、动作、终态]。
最终采用[画风与声音]。
```

## 粗粒度白模

粗粒度白模负责动作路径、人物调度、站位、进出场、运镜、切镜、光影变化和声音节奏。逐一映射几何体：

```text
@视频1是粗粒度白模，只提供动作路径、人物站位、机位、运镜和切镜，不采用白模外观、材质和空白场景。
@视频1中的高圆柱体对应<人物A>；长方体对应<道具A>。
@图片1定义<人物A>的身份与服装；@图片2定义<道具A>；@图片3定义最终场景。
保持白模时序与空间骨架，不保留白模材质、轨迹线、坐标轴、控制器和相机锥体。
```

附属肢体或翅膀只有动作链完整时才继承；不完整的低模动作会导致僵硬。

## 细粒度白模

细粒度白模已有完整结构，保持几何、比例、动作、空间、机位、运镜和切镜，只重渲染人物、材质、颜色、场景和风格：

```text
将@视频1的细粒度白模动画渲染成最终成片。
保持结构、动作、空间布局、机位、运镜和切镜；不采用灰模材质和空白背景。
@图片1定义最终人物/材质；@图片2定义最终场景、光线和视觉风格。
```

## 判断白模类型

- 结构粗、几何体简单、主要价值是走位和摄影机：粗粒度白模。
- 模型、装置或场景结构已经完整，只缺材质和成片美术：细粒度白模。

## 摄影机已设计的 Blender 白模

需要可控摄影路径时加载 [摄影预演交接](../director/blender-camera-previs.md)。采用 `CAMERA_PREVIS` 显式继承动态构图与相机时序，分别声明是否继承人物动作和灯光；不把它降为只参考站位的 `LAYOUT_ONLY`。首尾参考和视觉锚点须与预演同版且相容。
