# 摄影光学：焦距、FOV 与可见结果

对生成模型，数字是辅助，**可见结果**是主指令。推荐把传统摄影语言和画面结果绑在一起写。

## 推荐格式

```text
OPTICS：约50mm等效 / 中等FOV；人物占画面高度约55%；透视自然，背景轻度压缩但仍可辨；浅景深只让后景柔化，不吞掉空间锚点。
```

超长焦可以写：

```text
约200mm等效，FOV≈12°；明显背景压缩；摄影机远离主体；人物清晰，背景形成柔和色块；允许前景虚化遮挡帮助建立观察感。
```

## 原则

- **焦距**、FOV 和构图内容要一致：极广角不要同时要求远处小脸保持肖像级细节；极长焦不要要求同时展示完整大空间。
- 如果模型对毫米数执行不稳定，保留毫米作为摄影意图，同时补充 FOV、主体占屏比例、透视压缩、景深和前景关系。
- 一颗镜头先有一个主摄影意图；复杂运镜写起点、路径、终点。

## 器材名称与可见效果

摄影机、胶片和镜头名称可作为风格锚点；使用时补充本镜需要的可见特征，如焦外形状、边缘表现、颗粒或高光晕染。保留用户指定的器材，但不宣称模型精确模拟其成像。

区分拍摄介质、镜头特性与后期处理。数字摄影叠加胶片质感可以成立，应说明是后期风格；不要无区别叠加胶片片门抖动、传感器噪声和多套器材名称。仅按当前画面目标选择特征，不默认添加颗粒、眩光或浅景深。

示例（仅当这些效果是目标）：数字摄影、变形宽银幕镜头风格；远处点光源呈椭圆焦外，边缘轻微软化，皮肤保留毛孔；后期加入少量细腻胶片颗粒和轻微高光晕染。

器材名称是否有独立作用，按现有控制变量实验验证；单个公开案例不足以证明某个名称有效。

## 来源边界

“十档 FOV 锚点”“某个角度区间最稳定”等属于外部项目的**项目经验**，**不是 Seedance 官方硬规则**。可以用于测试和诊断，不应写成所有平台的模型事实。

## Blender 预演口径

预演须记录实际焦距、传感器尺寸、Sensor Fit、画幅以及 FOV 是水平/垂直/对角。不要将本页的约略等效数字直接当作相机参数。固定机位换焦距不改变透视关系；维持同景别而改变机距才改变前后景关系。精确配置与屏幕结果按 [摄影预演](../director/blender-camera-previs.md) 交接，生成 Prompt 保留可见意图。
