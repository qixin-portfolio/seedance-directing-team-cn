# 声音、口音与对白稳定

声音分为：对白内容、说话人、VOICE PROFILE、环境声、动作音效、音乐。每类都要有明确归属。

## VOICE PROFILE

关键角色建立固定 `VOICE PROFILE`，建议包含：

- 年龄与声线范围；
- **音域** / register；
- **音色** / timbre；
- **语速**与节奏；
- 说话方式；
- **口音**类别及 1–3 个可听见的语音特征；
- 当前场景的强度变化。

为了减少跨镜漂移，已确认的 VOICE PROFILE 在同一项目中**逐字复用**；场景变化只附加 HERE / SCENE MODIFIER，不改核心描述。

## 台词与口型

- 一句台词必须能在当前时长自然说完；
- 严格口型时确保脸和嘴可见，不在词中切镜；
- 多人同框明确每句归谁，其他人物不误说、不误唱；
- 高难度口型或口音可拆成一人一句的短 clip，这是生产策略，不是模型硬限制。

## 说话者与听者双轨

对白场景同时维护两条轨道：

- **SPEAKER TRACK**：人物目的、保护策略、触发词、停顿、呼吸、语气变化和说完后的状态。
- **LISTENER TRACK**：听者在触发词前保持什么状态，听到触发词后从哪一个微反应开始变化；不要让听者提前完成结论。

切镜可以让台词以画外音或声音桥延续，但必须保持说话人、声源方向、视线关系和房间声场一致。不要在一个词中间切断口型，也不要让反应抢在触发词之前。

## 台词时间预算

估算公式：

`镜头所需时长 = 台词口播 + 说前停顿/动作 + 听者反应 + 结尾余韵`

普通中文对白可先按约 3–4 字/秒估算；克制、迟疑或哭腔按约 2–3 字/秒估算。实际以自然表演为准：塞不下时先缩短台词或拆镜，不加速口播，不删除改变剧情的关键信息。

## Seedance 特殊字符（本 Skill 的唯一权威写法）

- 音乐：`()`
- 音效：`<>`
- 台词：`{}`
- 字幕：`【】`
