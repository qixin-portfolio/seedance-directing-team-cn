# Seedance 2.0

本文件是版本工作流参考，不等同于平台官方语法。括号、路径名称和结构标签属于本项目约定；具体能力、素材上限和入口仍需按当前 Surface 核验。

## 任务类型

- 多模态参考：参考图片、视频或音频生成新视频。
- 编辑视频：在原视频上增加、修改或删除明确元素。
- 延长视频：向前或向后续写原视频。
- 组合任务：用一份素材的指定维度编辑另一份视频。

编辑或延长时直接写“严格编辑 @视频N”或“向后延长 @视频N”，不要写成“参考 @视频N”，避免任务误判。

## 路径 A：简单任务

适用于一个场景、一个主要变化、一个连续动作或一次局部编辑。

结构：

`任务句式 + 主体与素材绑定 + 场景和动作 + 简短风格与稳定约束`

示例骨架：

`参考 @图片1 中的<主体1>，生成她在窗边完成[动作]并停在[终态]的画面。暖色自然光，稳定电影质感，无字幕、无水印、无Logo。`

## 路径 B：复杂影视化任务

适用于两个及以上镜头、多事件、空间变化、对话往返或多主体互动。

### 第一段：总体设定与主体定义

一次性绑定人物、场景、道具、动作参考和声音参考。重要身份素材前置。

### 第二段：镜头顺序

使用“镜头1、镜头2、镜头3”。每镜按以下顺序：

1. 一个主要运镜；
2. 主体动作与表情；
3. 位置和空间变化；
4. 台词、音效或环境声；
5. 可观察结束状态。

执行**一镜一运镜**。不要在同一镜头叠加推、拉、摇、移。复杂任务采用**镜头顺序优先**，不要依赖精确绝对秒数。

### 第三段：风格和约束

只保留保护身份、服装、动作、多人区分、字幕、Logo和画面稳定的必要约束。

## 八大要素自检

`精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件`

主体和动作必须明确；其余按任务需要补充。动作优先采用清楚、连续、幅度适中的过程，并写出终态。

## 素材引用

- 使用 `@图片N / @视频N / @音频N`。
- 不在动作描述里裸写无语义的 Asset ID；遵守 **Asset ID 屏蔽**。
- `@图片N` 不直接紧接动词或方位词。写成“@图片1 中的女生”或先定义 `<主体1>`。
- 多主体时分别命名、分别绑定，禁止用“图片1到图片4分别对应四个人”这种模糊写法。

## 多人稳定

每个人分别锁定脸、发型、服装、体型、画面位置、动作和台词。多人正面动态时使用清晰左右方位，避免互换身份、服装、动作、声音和分身。

## 声音与文字符号

符号统一见 [声音系统](voice-system.md)：音乐 `()`、音效 `<>`、台词 `{}`、字幕或标题 `【】`（均为半角括号，字幕为全角方头括号）。

小语种台词先标注语言和口音。字幕等画外文字在后期完成；招牌、标签等画内文字由资产图承担，视频中写“保持文字不变”，见 [画内文字系统](in-world-text.md)。
