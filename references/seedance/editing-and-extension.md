# 视频编辑、延长与转场

## 视频编辑总公式

`唯一编辑母版 + 精确对象/区域 + A→B变化 + 编辑范围/时间 + 保持内容`

```text
【编辑目标】
编辑@视频1，只在[时间/区域]把[对象A]修改为[对象B]。

【原视频职责】
@视频1是唯一编辑母版，负责人物、场景、动作、构图、遮挡、镜头、声音和事件顺序。

【目标素材职责】
@图片1只用于[目标对象属性]，不采用背景、人物或构图。

【编辑范围】
只处理[对象、区域、时间或声音类别]。

【保持内容】
保持@视频1中的[身份、服装、动作、机位、背景、光影、声音、节奏]不变。
```

局部问题优先编辑，不重写整段。

## 主体替换

目标对象继承原对象每次出现、运动、遮挡和离场的时点、路径、持续时长和速度变化。明确全片数量，避免原对象和替换对象同时存在。

## 背景替换

只修改主体轮廓之外的背景区域。保持人物身份、面部、服装、表情、位置、大小、动作和遮挡关系；目标背景控制空间、材质、景深、环境色和光线方向。

## 声音编辑

分别指定对白、语言、音色、背景音乐、环境声和动作音效：

```text
编辑@视频1，只移除背景音乐；保留人物对白、口型、环境声和动作音效。画面、镜头、时长和剪辑节奏保持不变。
```

## 向后延长

新增片段第一个画面直接承接原视频尾帧：

```text
@视频1是需要向后延长的原视频。
向后延长@视频1。延长片段第一个画面保持[人物姿态与朝向]、[道具位置]、[背景关系]、[机位构图]、[光线]、[声音状态]和[运动趋势]连续。
随后，[新的动作或事件]，结束于[明确终态]。
全过程保持[身份、服装、道具、背景、轴线和声音]连续；同一主体不重复、不分裂。
```

不要重演已经完成的动作。

## 向前延长

先写原视频开始前的事件，再把新增片段最后画面明确写成原视频首帧：

```text
向前延长@视频1。在原视频开始之前，[前置动作]。
延长片段最后一个画面自然衔接@视频1首帧：[姿态、朝向、道具、人物站位和背景关系]；保持机位、光线、声音和运动趋势一致。
[只在原视频开始后出现的对象]不得提前出现。
```

## 无缝转场

```text
@视频1是转场前片段，采用其尾部主体、构图、运动和声音。
@视频2是转场后片段，采用其开头主体、构图、运动和声音。
在@视频1尾部，[共享载体]沿[方向]运动并遮满/占满画面，在过渡中转化为@视频2开头的[对应载体]。
衔接点的位置、尺寸、速度、方向、光线、运动模糊和声音连续，最后自然到达@视频2开头构图。
```

“平滑转场”必须有物理载体：遮挡、形状、颜色、动作、视线、物体、光线或粒子。目标是自然衔接，不是逐像素不变。

## 延长边界检查

边界画面同时检查人物姿态、道具、机位、光线、声音和运动趋势。
