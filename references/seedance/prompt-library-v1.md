# 提示词模板库 V1 路由卡

使用方式：先判断镜头目的，再选择最接近的模板。只调用核心结构和必保项，不机械复制模板全文。一个镜头可组合一个主模板与一个辅助模块。

## 1. `TPL_ONE_TAKE_COMPLEX_ACTION`

**触发：** 单镜头内有明确动作链、空间方向和物理反馈。  
**公式：** 首帧空间锁定 → 因果动作链 → 状态持续 → 明确终态。  
**必保：** 世界方向、摄影机方向、人物朝向、道具状态。  
**风险：** 动作过密、方向混乱、镜头结束后继续表演。

## 2. `TPL_MULTI_CUT_PROJECTILE_ACTION`

**触发：** 投射物、追击、撞击或高速动作的多镜头组合。  
**公式：** 空间建立 → 决策 → 投射物跟随 → 撞击结果。  
**必保：** 每镜速度单一；速度变化只发生在切镜处；投射物方向连续。  
**风险：** 同镜头多速度、多方向、撞击前后状态不一致。

## 3. `TPL_MUSIC_VIDEO_PERFORMANCE_EDIT`

**触发：** 音乐表演、舞蹈、群演围合、节拍剪辑。  
**公式：** 身份锁定 + 音频锁定 + 导演命题 + 群体功能 + 节拍图。  
**必保：** 主表演者层级、群众动作职责、音乐与剪辑同步。  
**风险：** 群演抢戏、镜头与音乐无因果、身份漂移。

## 4. `TPL_LIPSYNC_PERFORMANCE_VIDEO`

**触发：** 唱歌、对白表演或严格口型。  
**公式：** 唯一音源 → 台词/歌词时间段 → 面部可读 → 不在词中切镜。  
**必保：** 只有指定人物张口；其他人不误唱；声音归属明确。  
**风险：** 侧后脸又要求可验收口型、台词超过时长。

## 5. `TPL_SPLITSCREEN_CHARACTER_REFERENCE_SHEET`

**触发：** 左右分栏人物资产，一边全身、一边肖像。  
**公式：** 中性身份展示 + 统一棚拍 + 服装材质清楚 + 两面板一致。  
**必保：** 同一身份、同一服装、比例和背景统一。  
**风险：** 两面板生成成两个人、背景和光线不一致。

## 6. `TPL_FOUR_SHOT_CHARACTER_ID_LOCK_SHEET`

**触发：** 正面肖像、侧面、全身正面、全身背面四视图。  
**公式：** 原创身份 + 中性视角 + 服装/道具结构 + 尺度对齐。  
**必保：** 四张为同一人物；表情中性；服装结构不漂移。  
**风险：** 多视图被理解为多人；高风险道具或文字变形。

## 7. `TPL_ENSEMBLE_CASTING_LINEUP_REFERENCE`

**触发：** 多人选角、群像母版、统一世界观。  
**公式：** 精确人数 + 差异矩阵 + 同场景同光线 + 无重复。  
**必保：** 年龄、体型、脸型、服装、站姿差异。  
**风险：** 人数过多导致脸太小；应先群像母版，再拆个人资产。

## 8. `TPL_LIVE_ACTION_MINIATURE_CHARACTER_INTERACTION`

**触发：** 真人与微型角色、混合媒介、门户或飞行动作。  
**公式：** 真人空间 + 微型角色风格保持 + 共享光影 + 尺度与遮挡锁定。  
**必保：** 接触阴影、景深、遮挡、飞行物理、完整离场路径。  
**风险：** 微型角色被写实化、漂浮无重量、尺度忽大忽小。

## 9. `TPL_CONTINUOUS_DAYLIGHT_TIMELAPSE_PORTRAIT`

**触发：** 人物实时表演与环境时间流逝同时发生。  
**公式：** 实时人物层 + 压缩环境光层 + 连续光线变化 + 情绪连续。  
**必保：** 人脸活着、光线来自真实方向、人物动作少而连贯。  
**风险：** 同时安排过多动作；景深过浅导致多层信息不可读。

## 10. `TPL_THREE_CHARACTER_ROMANCE_POSTER_KEYVISUAL`

**触发：** 三人关系海报、爱情或三角关系主视觉。  
**公式：** 中心情感锚点 + 一侧开放亲近 + 一侧疏离但注视。  
**必保：** 身体距离、接触、视线和留白共同叙事。  
**风险：** 引用人物对应错误、三人关系不清、标题空间不足。

## 11. `TPL_QUIET_MULTI_SHOT_DIALOGUE_TASK_SEQUENCE`

**触发：** 日常对话与小任务，低冲突、多镜头。  
**公式：** 进入空间 → 接收信息 → 完成任务 → 清楚结果。  
**必保：** 主空间与邻接空间关系、道具重量、结果轮廓。  
**风险：** 把多镜头误写成一镜到底；时长不足；道具挡脸。

## 12. `TPL_OFFSCREEN_TRIGGER_REACTION_SEQUENCE`

**触发：** 关键事件发生在画外，主角通过配角提醒产生微反应。  
**公式：** 稳定状态 → 画外触发 → 环境变化 → 配角干预 → 主角刚开始反应。  
**必保：** 不切到触发源；局部空间锚定；反应未完成即结束。  
**风险：** 画外声音不清、配角抢戏、主角提前完成动作。

## 13. `TPL_DIALOGUE_HANDOFF_DEFERRED_REVEAL_SEQUENCE`

**触发：** 人物A通过对白和手势把注意力交给新人物B，并延迟正脸。  
**公式：** 权威触发 → 对白宣布 → 手势驱动横摇 → 侧面揭示 → 小步入位。  
**必保：** 摄影机只向一个方向交接；B不完整正脸、不提前说话。  
**风险：** 群演数量与景别冲突；画外台词又要求可见口型。

## 14. `TPL_OFFSCREEN_CUE_INNER_SHIFT_SEQUENCE`

**触发：** 角色走神，画外声音把注意力拉回并产生兴趣。  
**公式：** 眼神失焦 → 画外秩序信号 → 眼神聚焦 → 头部跟随 → 兴趣形成。  
**必保：** 心理变化先发生在眼睛；不是震惊，而是克制兴趣。  
**风险：** 把失焦误作画面模糊；“无聊”与“游离”概念混淆。

## 15. `TPL_EXACT_FIRST_FRAME_PULLBACK_CHAOS_REVEAL`

**触发：** 精确首帧继承，连续后拉揭示巨大环境或反转。  
**公式：** 首帧锁定 → 微动作入位 → 中心静止 → 外围混乱 → 分层后拉揭示。  
**必保：** 原脸、配饰、皮肤和纹理跨帧延续；摄影机单一连续后拉。  
**风险：** 水位/尺度逻辑错误、群演过多、人脸稳定要求不现实。

## 16. `TPL_STOPMOTION_PAINTERLY_DRAMATIC_CONFRONTATION`

**触发：** 手绘油画定格动画、低动作高情绪对峙。  
**公式：** 风格与运动机制分离 + 人物抽帧 + 气氛连续 + 面部表演 + 空间边界。  
**必保：** 人物按twos、气氛层平滑但保持手绘；构图表达冲突与分离。  
**风险：** painterly boil破坏五官；表情弧线过多；长总提示词压垮执行。

## 17. `TPL_PORTRAIT_PLUS_GHOST_MANNEQUIN_OUTFIT_SHEET`

**触发：** 右侧人物头像、左侧幽灵人台整套穿搭。  
**公式：** 身份资产 + 服装资产分栏 + 统一棚拍 + 材质廓形清楚。  
**必保：** 左侧无真人、无塑料人台硬件；右侧身份不漂移。  
**风险：** 两面板风格不统一、衣服漂浮不自然、服装文字错误。

## 18. `TPL_PHASED_PHYSICAL_ACTION`

**触发：** 跳跃、坠落、拉扯、攀爬、撞击、打开阻力物件或其他需要明确相位的连续物理动作。  
**公式：** 力量来源 → 接触 → 传力 → 主要阻力 → 承受对象反作用 → 回弹 / 衰减 / 稳定终态。  
**必保：** 只选当前镜头必要相位；明确质量、材料、接触点、反作用和 endpoint。  
**风险：** 机械塞满所有相位、只写施力主体、动作完成后持续乱动。

## 19. `TPL_CAUSAL_LOAD_PATH_COVERAGE`

**触发：** 全景同时包含多个接触点、材料失效或受力传递，连续生成后因果仍不可读。  
**公式：** Geography → Force Source Insert → Load Path Insert → Failure Point Insert → Result / Reaction；只取观众理解因果所需的最少镜头。  
**必保：** 同一受力方向、材料状态、空间关系和时间进程；每个 Insert 都必须推进同一因果链。  
**风险：** 用特写掩盖空间缺失、重复展示同一信息、各镜受力方向互相矛盾。

## 组合规则

- 主模板决定镜头结构；辅助模块只补一种能力，例如口型、首帧锁定或群体稳定。
- 复杂物理动作先选 `TPL_PHASED_PHYSICAL_ACTION`；只有整体动作因果不可读时，才改用或辅助加入 `TPL_CAUSAL_LOAD_PATH_COVERAGE`。
- 同一生成任务不要同时塞入三个以上母模板。
- 若两个模板要求相反的摄影或节奏，拆成不同镜头或不同生成任务。
- Seedance 2.0复杂场景将模板装入路径B；Seedance 2.5将模板装入参考声明、阶段/时间戳和全局锁定结构。
