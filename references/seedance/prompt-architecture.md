# 提示词架构

## 基础骨架

Seedance 官方基础逻辑仍是：

`主体 + 动作或事件 + 场景 + 视觉 + 镜头 + 声音`

先写“谁发生什么可见变化”，再补环境、风格和摄影。画质词不能替代人物、动作和终态。

## Compact Prompt

适合一个场景、一个主要变化、低风险单镜或局部编辑：

```text
[素材职责（有素材时）]
[主体]在[场景]中从[起始状态]完成[主要动作]，最后停在[可观察终态]。
镜头从[起点景别和位置]以[一个主要摄影意图]到达[终点构图]。
[物理光源]形成[可见光影]。
声音包括[环境声/音效/对白/静音]。
全程保持[身份、服装、道具、空间]稳定；[字幕/BGM/Logo政策]。
```

单一连续动作不强制时间戳。

## Production 15-Block

当镜头包含多人、复杂动作、精确空间、台词、反复返修或高连续性风险时，切换到 [Production 15-Block](production-15-block.md)。它是生产结构，不是 Seedance 官方规定；价值在于让 Auditor 能检查、Workbench 能只 patch 一个区块。

## 多镜头分镜

一条生成里包含 2 个以上镜头的叙事段，使用 `assets/video-prompt-template.txt`（【镜头N】逐镜结构，含声音行），规则见 [提示词导演](../director/prompt-director.md)。Seedance 2.0 下它就是“路径 B”的展开写法，保持一镜一运镜（2.0 额外从严，见下文“摄影”）。

## 动作

使用：`起始状态 → 触发 → 过程 → 物理反馈 → 终态`。

- 写手、头、肩、重心、视线和速度变化；
- 接触物体时说明重量、惯性、反弹、拖拽或液体/布料反馈；
- 复杂物理动作按 [物理动作与因果 Coverage](../director/physical-action-design.md) 选择相位母式，补全力量来源、接触点、传力路径、阻力、承受对象反作用和稳定 endpoint；
- 复杂动作不要藏在中段；必要时让首帧已经处于动作将起或关键动作刚开始的状态；
- 同一失败反复出现时拆镜或换机位，不用更多形容词硬压。

## 情绪与演技

简单镜头可把情绪翻译成 2–4 个可观察表现；角色连续项目加载 [表演指导](../director/performance-direction.md)，使用角色表演档案 + 场景适配与刺激—动作链。

## 摄影

焦距、FOV、主体占屏、透视、景深和前景关系共同描述。数字只辅助，**可见结果优先**。详见 [光学与 FOV](optics-fov.md)。

每镜保持一个主要摄影意图；可以用位置与朝向等协同的复合运动实现，见 [摄影指导](../director/cinematography-direction.md)。已有 CAMERA_PREVIS 时继承其路径，不因复合运动机械拆镜。Seedance 2.0 文字驱动时仍按一镜一运镜从严处理。

## 声音

明确自然环境声、动作音效、对白、授权音色参考、音乐或静音。台词匹配时长和说话人；跨镜声音稳定加载 [声音系统](voice-system.md)。

## 整体声音与光影基线

多镜头、对白、悬疑、动作、续写或声音/光影承担叙事功能时，在 Prompt 中增加一段全局基线：

```text
【整体声音与光影】
声音：无配乐/按需求保留音乐；固定 2–4 个环境声锚点，关键台词或情绪转折时说明声场变化，结尾保留自然衰减。
光影：可信主光源从明确方向照入，冷暖、肤色、眼部高光和阴影方向保持连续；只在人物移动、门窗、屏幕或天气变化时改变。
```

普通镜头至少写一个有动机的光源和 2 个具体声音；不要用“电影感光影”“沉浸式音效”代替来源、作用和可听见的结果。除非用户要求或场景需要，不默认添加背景音乐。

## 提示词压缩阶梯

提示词过长时按顺序压缩：

1. 删除重复风格词和装饰性形容词；
2. 合并全局环境、声音和光影描述；
3. 合并同义微表情或次要反应；
4. 压缩动作链中的非关键中间步；
5. 最后才减少镜头、事件或拆分片段。

不得优先删除素材职责、身份锁定、空间方向、动作因果、关键台词、终态或结尾余韵。字符数是压缩参考，不是 Seedance 的硬上限；多模态正式镜头以 Production 15-Block 和 Prompt Auditor 的可控性为准。
