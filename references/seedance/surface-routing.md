# 平台路由（Surface Routing）

Seedance 版本与使用平台是两个维度：先判断**模型版本**，再判断**平台 Surface**。同一个 Seedance 2.5 在即梦、Higgsfield、API 或第三方路由上的参数、功能入口、素材限制和计费方式可能不同。

## 三层事实

- **模型能力**：模型本身可以理解或生成什么。
- **平台能力**：当前即梦、Higgsfield、API 等实际暴露什么模式、参数和素材入口。
- **单次遵循度**：某次生成是否按要求执行，不等于能力是否存在。

不得把一个平台的限制外推成所有平台的统一限制。

## 平台事实记录

凡涉及素材数量、时长、分辨率、模式、音频、编辑入口或计费的具体结论，必须记录：

```text
SOURCE：官方文档 / 当前界面 / API 文档 / 用户提供资料
CHECKED_AT：YYYY-MM-DD
SURFACE：即梦 / Higgsfield / API / 其他
CONFIDENCE：已核验 / 条件性 / 未核验
```

未核验的数字只能作为“待确认条件”输出，不能写成跨平台硬规则。

## 路由顺序

1. 用户明确平台：按该平台组织设置与上传方式。
2. 用户只说 Seedance 版本：先写跨平台有效的提示词结构；参数只给保守建议。
3. 任务依赖当前模式、分辨率、时长、参考数量或编辑入口时：优先做**实时核验**（官方文档、平台工具或当前 UI）。
4. 无法实时核验时：明确“提示词方法可用，具体平台参数以当前界面为准”，不要猜。

## 常见 Surface

### 即梦

优先遵循用户提供的官方 2.5 / 2.0 指南和当前 UI。编辑、延长、首尾帧等任务遵守该界面自动锁定的参数规则。

### Higgsfield

把 Higgsfield 当作独立平台 Surface。若当前模型目录可查询，先读取 Seedance 版本对应的 `mode / duration / resolution / references / audio` 等真实参数，再推荐设置；不要照搬即梦页面参数。

### API / 第三方

先确认 API 文档或路由商当前暴露的模型 ID、参数和输入格式。提示词中的叙事、素材职责和连续性原则可以复用，但平台参数不能从其他 Surface 推断。
