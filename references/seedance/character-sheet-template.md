# 人物资产设定板模板（写实棚拍 · 16:9 五格）

用户定的人物资产标准模板（2026-11-02，项目经验，P 类）。有参考图、要把人物出成可进视频生产的设定板时，默认用这一版；用户另有要求时以用户为准。

## 用法

1. **参考图是唯一身份基准**：出图时必须把选定的人物图作为输入图，不另起五官。
2. 只替换两个槽位：
   - `{人物锁定}`：一句话写年龄段、性别、服装结构和颜色、鞋。服装照参考图写，不加新配饰，不加工牌、Logo、文字。
   - `{姿态变体}`：站立人物留空；不能站立的人物（坐轮椅、卧床）按下文“姿态变体”替换三格全身的写法。
3. 其余段落**逐字使用**，不按人物改写。
4. 出图后逐格检查（见“验收”），不合格只重出那一张。

## 提示词正文

```text
以参考图人物为唯一身份基准，生成人物资产设定板，五官、脸型、发型、发色、肤色、体型、服装、身高比例在所有面板中完全一致，不重新设计五官。
人物：{人物锁定}

画布：横向16:9；左侧占画面2/3，由三等分竖向全身面板组成；右侧占画面1/3，由上下两等份脸颈面板组成，面板之间使用细冷灰分隔线。背景为浅灰纯色无影摄影棚，均匀干净、无纹理、无杂物、无人物投影。

左侧第1格：无头正面全身，从锁骨上方自然截断至鞋底。头部、下巴和脖子不得出现；截断处只保留完整衣领开口与背景。服装露出的肩部、锁骨、胸腹必须呈现自然肤色与连续皮肤，不得被布料或灰色留白覆盖。

左侧第2格：无头严格90度左侧全身，从锁骨上方自然截断至鞋底。头部、下巴和脖子不得出现；服装露出的肩部、侧胸与腹部保留自然皮肤和原有服装结构。

左侧第3格：严格背面全身，从完整头部、头发至鞋底，保留完整服装背面、裤装与鞋。

右侧上格：正脸与脖子特写，双耳清洁无饰品，颈部无耳机。

右侧下格：45度左侧脸与脖子特写，双耳清洁无饰品，颈部无耳机。
{姿态变体}

皮肤达到皮肤学研究摄影级真实：单个毛孔具有真实深度、不是噪点模拟；自然眼睑褶皱、眼下细小皱纹、睫毛投下的细柔阴影、脸颊轻微不均匀纹理；皮肤表面的桃绒毛在侧向柔光下可见极细反光；额头、鼻梁、颧骨凸面有克制的天然皮脂光泽，其余位置自然衰减，绝不油亮磨皮；皮下有毛细血管泛红与局部冷暖差异，不是均匀单一肤色。

布光：专业棚拍全局柔光，主光位于人物正面略偏侧，大面积深抛柔光箱，色温约5200K，中性不偏黄不偏蓝；加非常克制的暖色轮廓光使人物边缘从背景分离；特写中眼睛保留柔和清晰的矩形眼神光；面部光影过渡柔和，但不把皮肤打平，骨骼结构与皮肤起伏的微阴影必须保留。

镜头与质感：特写用85mm f/2.0精确对眼，全身用50mm f/5.6，人物比例与服装材质清晰；零数字锐化，清晰度全部来自真实光学解析力；黑位轻微抬升、暗部不死黑；加极轻微、均匀的胶片细颗粒。
```

用户原稿有两处笔误已改：“真实照片恐慌”→“真实照片质感”；“不要数字噪音点与噪音噪音点”→“不要数字噪音点”。其余逐字保留。

## 姿态变体

人物设定不能站立时，不能为了模板让他站起来。`{姿态变体}` 写成：

```text
姿态说明：此人物不能站立，三个全身格一律坐在轮椅上（轮椅同参考图），保持同一坐姿。第1格为无头正面坐姿全身，第2格为无头严格90度左侧坐姿全身，第3格为背面坐姿全身（轮椅靠背会挡住部分背部，保留完整头部和头发）；从锁骨上方截断至鞋底与轮椅脚踏。{患侧/固定姿态，如：左手微屈搭在大腿上，右手扶扶手}。
```

卧床人物同理，改成“半躺在床上”，并写清哪一侧受限。

## 出图（Codex）

- 参考图作为输入图传给图像工具，提示词里写“以输入图人物为唯一身份基准”。
- 设定板提示词很长，Codex 一次 exec 往往只出 1 张就结束（2026-11-02 实测）：按“一次 exec 一张图”拆，多路并行。
- 画幅要求 16:9；工具只给 3:2 时保留 3:2，不裁切（裁切会切掉面板）。

## 验收

逐格放大检查，以下任一不过即重出该张：

1. 第1、2格看不到头和下巴；截断在锁骨以上、衣领完整。“锁骨上方截断”会留一小截颈根，属正常，不算失败；露出明显的脖子才重出。
2. 第2格是严格 90 度侧面，不是 3/4 侧。
3. 第3格是正背面，头和头发完整。
4. 五格是同一个人：脸、发型、发色、肤色、服装颜色和结构一致。
5. 两个脸格耳朵无饰品、颈部无耳机；正脸格对眼清晰。
6. 皮肤有毛孔和细纹，不磨皮、不油、不塑料；没有数字锐化的白边。
7. 全图没有文字、Logo、水印、工牌；背景无投影。
8. 姿态变体人物没有被画成站立。
