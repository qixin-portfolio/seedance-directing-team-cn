# 镜头配方资料库（video-shotcraft adapter）

这是一个**只读镜头语法资料库**，不是第二个总导演，也不是完整产品宣传片生产流程。

来源：[Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)

该仓库目前提供 152 张镜头配方卡，主要面向 Remotion 产品宣传片。当前 Seedance Skill 只借用卡片中的：镜头意图、能量、建议时长、运动路径、节奏比例、转场语义和已知坑。不要把其 Remotion 代码、完整模板、音频资产、剪映导出或六阶段生产流程带入 Seedance 任务。

## 何时调用

当用户：

- 指定某张 `video-shotcraft` 镜头卡或 Gallery 卡名；
- 想为一个产品、道具、建筑或人物选择更具体的开场、展示、转场、节奏或收尾运动；
- 需要把“聚光锁定、卡片弹起、俯冲落点、甩镜接缝、穿窗转场”等动效语法翻译成 AI 视频镜头。

普通写实剧情、人物表演、物理动作和多模态素材控制，不因调用镜头配方而改变原有 Seedance 路由。

## 选卡与翻译流程

1. **先定镜头功能**：是建立空间、锁定主体、展示结构、强调变化、连接两镜，还是收束品牌信息。
2. **选一个主配方**：一条镜头只选一个主配方；必要时最多加一个辅助配方。转场接缝一式一用，不叠加多个转场。
3. **读取卡片信息**：至少读取一句话意图、适用场景、时长/能量、参数表和已知坑。用户点名卡片时，按仓库 `references/shots/` 的准确文件名查卡，不凭名称臆造参数。
4. **翻译到 Seedance**：
   - 意图 → `SCENE CONTEXT / SHOT PURPOSE`；
   - 时长与能量 → `ACTION TIMING / DELIVERY INTENT`；
   - 相机与运动曲线 → `OPTICS / CAMERA` 的一条物理可行路径；
   - 起伏、悬停、落定和停留 → `ACTION TIMING / FINAL STATE`；
   - 已知坑 → Named Lock、正向约束或 Prompt Auditor 检查项；
   - 声音提示 → `AUDIO` 的环境声、动作音效或音乐政策，不直接搬运仓库音频文件。
5. **回到总导演审计**：检查素材主控制源、空间地理、人物身份、轴线、动作因果、声光连续和终态。配方不能覆盖用户明确要求，也不能夺取 `@图片N` 的 Reference Role。

## 分类索引

按功能查找，不按仓库的完整 Remotion 工程路由：

| 类别 | 可借用的 Seedance 语法 | 常见用途 |
|---|---|---|
| `camera` | 俯冲、拉远、环绕、纵深推进、空间揭示 | 建立场景、展示建筑/产品空间、从全局落到主体 |
| `opening` | 聚光锁定、主角卡升起、升降揭示、材质化开场 | 开场建立唯一视觉主体 |
| `effects` | 扫描、冲击、光束、聚合、落定反馈 | 强调一次关键变化，不做群体闪烁 |
| `transition` | 流白、暗场滑行、焦点接力、甩镜、穿窗 | 两镜之间的语义接缝 |
| `rhythm` | 节拍切换、速度坡、定格、蒙太奇分组 | 音乐或动作节奏明确的镜头组 |
| `outro` | 退场、收缩、溶解、标识锁定 | 结束段和品牌余韵 |
| `interaction / ui-entrance / data / typography` | 元素入场、列表堆叠、数字滚动、字卡运动 | 只在画面确实包含 UI、数据或文字时翻译 |

有用的代表卡（仅作检索入口）：

- `space-camera-moves`：全局俯冲到主体、空间纵深展示；
- `spotlight-hero-card`：聚光锁定单一主体，推进、悬停、落定；
- `shot-transitions`：流白、暗场、焦点、甩镜、穿窗六类接缝；
- `beat-cut-moves`：节拍驱动的镜头组切换；
- `impact-feedback`：一次关键动作或信息变化的冲击反馈。

## Seedance 适配边界

- **可直接借用**：主运动方向、起承转合、速度比例、停留时间、转场语义和视觉焦点层级。
- **需要重写**：CSS/3D 参数、Remotion easing、组件名、页面截图层级、代码实现和音频文件名；它们不是 Seedance 的可执行语法。
- **写实场景限制**：卡片里的“卡片弹起、页面炸开、UI 穿窗”只能转译为现实中有依据的物体、镜头或空间运动；没有真实受力或场景依据时，不强行套用。
- **多模态优先级**：素材职责、人物身份、场景 geometry、首尾帧、声音和 APPROVED 状态始终由 Seedance 生产规则管理。
- **输出边界**：调用资料库后仍只输出当前镜头需要的 Seedance Prompt 或镜头区块，不输出 Remotion 工程、模板流程或完整宣传片计划。

## 失败处理

- 卡片运动与场景地理冲突：保留戏剧功能，改成一条空间可行的运镜，并记录被放弃的卡片参数。
- 卡片要求产品 UI，但当前素材是实拍人物/建筑：只借用节奏和焦点逻辑，不复制 UI 动效。
- 卡片要求多种运动同时发生：拆成主配方和辅助配方，或拆镜；不要把多个运镜堆在一个镜头里。
- 卡片参数与用户判例、已锁定镜头或参考素材冲突：用户判例和 APPROVED 状态优先。
