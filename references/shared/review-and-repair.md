## 1. 审片顺序

先完整看一遍，不暂停列小问题。先回答：这场戏是否讲清、情绪是否抵达、观众是否知道该看谁、空间是否可信、摄影语言是否支持而非遮蔽主戏、最好的一刻在哪里。第二遍再按时间码记录问题。

始终先给总判断：**通过 / 有条件通过 / 需局部返工 / 需重新设计**。不要从车牌、皮肤纹理或小穿帮开始堆意见。

记录问题时关联镜头号、Take ID、提示词版本和可用区间；连续项目把结论写入 [三本账](continuity.md#5-三本账)。

## 2. P0/P1/P2 标准

**P0｜必须修**：叙事信息错误或缺失；人物身份、目标或关系看不懂；空间、方向、视点或动作因果崩溃；关键道具状态错误；表演与剧情状态相反；观众无法理解事件如何发生。

**P1｜优先优化**：情绪转折无过程；重要信息没有反应时间；节奏单一、长对白没有调度变化；背景像静止舞台；权力关系、危险感或人物入口不明确；相邻生成段有明显表演或构图接缝；构图、焦段、景深、运镜、速度或光线没有实现已确认的摄影命题。

**P2｜集中处理**：局部纹理、车牌、商标和小范围背景漂移；轻微光影、肤质和边缘问题；不影响理解的次要连续性；可统一替换的临时声音。

## 3. 问题来源（单选）

每个问题只选一个**主要**来源，再决定修法：

| 层 | 来源 |
|---|---|
| 导演 | 1 剧本/镜头设计（命题、节拍、调度）· 2 表演设计 · 3 群戏/环境设计 · 3b 物理因果、传力路径或承受对象反作用 |
| 资产与输入 | 4 人物资产 · 5 场景资产 · 6 道具资产 · 7 状态资产错误 · 8 素材职责冲突/参考污染/Reference Role 错误 · 8b 输入不可读（缺 Layout / Shot State Plate） |
| 提示词 | 9 首帧提示词 · 10 视频动作提示词 · 11 Scene Geography/轴线 · 12 摄影机或时间结构 · 13 声音与口型 · 14 提示歧义/区块矛盾 |
| 平台与模型 | 15 平台模式或参数不匹配 · 16 模型能力边界 · 17 模型随机性 |
| 后期 | 18 剪辑/声音/画质（更便宜在后期解决） |

## 4. 保护好表演

好表演比小连续性更难重现。若整场情绪成立，只出现抱膝/放腿、服装小错或轻微轴线问题，优先：删掉错误区间；插入主观人物反应；插入环境、道具或手部特写；裁切、放大或重新构图；Seedance 局部编辑；只补过渡状态；用声音和画外空间连接。

只有错误破坏叙事、空间或核心表演且无法被覆盖时，才扩大重做范围。

## 5. 处理方式与最小返工路由

由小到大依次判断：

1. **保留**：镜头目的完成，缺陷轻微。
2. **后期 / 剪辑可解**：删减、换序、延长反应、J/L cut、裁切、文字、混音、调色。
3. **Seedance 编辑**：主体、构图和动作正确，只错一个局部层（主体/背景/声音替换、局部修改），见 [编辑与延长](../seedance/editing-and-extension.md)。
4. **有限重抽**：提示词与资产结构正确，像随机性；同条件重抽 2–3 次为限。
4b. **Select**：整条结果不必全部使用；只有预先声明 MATERIAL SEQUENCE 或存在明确稳定叙事区间时，才记为剪辑候选，见 [生成实验与 Selects](generation-experiments-and-selects.md)。
5. **Workbench PATCH**：正式提示词大部分正确，只改失败区块，见 [Workbench](prompt-workbench.md)。
6. **单镜补拍 / 因果 Coverage**：补反应、关系、建立、动作关键状态、过渡或余波；主体动作基本正确但传力或失效点不可读时，保留主体镜头，只补解释因果所需的最少 Insert。
6b. **控制变量实验**：原因不明且存在两个可验证方案时，预先固定其余变量后比较，不把多项同时修改当成实验。
6c. **重建输入**：空间或第 0 帧状态靠文字反复失败时，补 Layout Plate / Shot State Plate，见 [输入设计](../seedance/input-design-and-previs.md)。
7. **重建资产**：同一身份/场景问题在不同提示词条件下重复出现，见 [资产压力测试](../seedance/asset-stress-test.md)。
8. **升级镜头设计 / 小节重做**：同一结构性失败反复出现——拆镜、减动作密度、换机位、让首帧处在关键状态。
9. **整场重设计**：场次目的、权威空间、主观视点或核心调度从根上错误。

第二次生成必须包含人类诊断并改变条件，不用同一条件连续抽卡。每轮只改变一个因果变量；该变量的必要依赖项可一起改，记为同一个“修改包”。不要用“高清、杰作、震撼、8K”掩盖错误资产或错误镜头。生成次数与成本只作 O 类估计。

## 6. 常见症状速查

| 症状 | 常见根因 | 首选修法 |
|---|---|---|
| 人物变脸 | 身份源或资产本身不稳 | 查 Canonical Descriptor 与压力测试；重复失败则重建资产 |
| 多人串脸或分身 | 角色相似、站位/职责不清 | 分别绑定身份、服装、锚点、动作、声音；减少同时互动 |
| 人物左右互换、场景翻面 | Scene Map 缺失或屏幕方向混用 | 恢复 SCENE GEOGRAPHY LOCK、轴线和可见锚点；停止补近景 |
| 参考素材泄漏 | 同一维度多个控制源 | 指定唯一主控制源，写明不采用内容，删除无职责素材 |
| 画面脏或塑料 | 低质参考传代、职责混杂 | 退回干净原图/线稿，减少参考职责 |
| 动作漂浮、僵硬、穿模 | 未拆状态、重量和接触 | 写起始→触发→过程→反馈→终态；必要时拆镜 |
| 施力有动作、承受对象不反应 | 只写动作主体，没有传力路径和反作用 | 补力量来源→接触→承受对象位移/形变→回弹或稳定 |
| 跳跃或坠落像漂浮 | 缺少加载、弧线、撞击和落地压缩 | 选择对应动作相位，保留起势、顶点/拉住、撞击与 endpoint |
| 门或机械自动打开 | 没有阻力、材料让位和身体过冲 | 写初次不动→加力→松动→突然让位→过冲稳定 |
| 全景动作看不懂因果 | 同镜包含多个接触点和结构失效 | 保留 Geography Shot，沿受力链补最少 Insert |
| 动作完成后持续乱动 | 缺少稳定终态 | 增加回弹、摆荡衰减、压缩恢复、减速或静止 endpoint |
| 布局图被当成首帧、构图被锁死 | Reference Role 未声明 | 标 `LAYOUT_ONLY` + `REFERENCE ONLY, NOT A START FRAME` |
| 复杂动作迟迟不发生 | 前置动作占满时间预算 | 让首帧靠近关键动作，或把接近过程拆到上一镜 |
| 镜头看不到关键动作 | 运镜装饰化 / optics 不匹配 | 只改 CAMERA 或 OPTICS，不动人物与美术 |
| 运镜花哨但没张力 | 无触发点、路径或结束构图 | 回到摄影命题，重写起点—触发—速度—落点 |
| 光斑、拉丝、flare、虚焦堆叠 | 光学效果无来源与时点 | 只保留一至两项主导效果并绑定光源/动作 |
| 对称构图主次不清 | 只写“对称” | 写明中轴、消失点、主体偏离规则和叙事焦点 |
| 情绪突然跳变 | 两段之间无过渡 | 补呼吸、收身、转移注意力等桥接 |
| 表情精致但像 AI 演戏 | 无对手刺激和可演动作，通道过载 | 改写刺激—调整—动作链，只保留少量关键通道 |
| 反应早于台词或事件 | 未定义反应时序 | 写明刺激发生后停顿、转移目光、再改变身体任务 |
| 台词都很快 | 未标重要信息与反应 | 揭示点加入停顿、反应和环境静默 |
| 台词评价无来源 | 剧本省略可见前因 | 台词前补失误、变化或动作证据 |
| 所有人盯主角、群戏同步 | 环境没有独立任务 | 逐人写任务、注意力、时点和强度 |
| 人物像巨人、建筑像模型 | 大全景没有尺度契约 | 用门高、人车比和层高重建比例 |
| 人物像贴在背景上 | 面部补光固定 | 写光区变化，取消无来源美颜光 |
| 烟、食物、门、伤妆跳变 | 无道具/动作状态机 | 写明初始、变化、结果并逐镜核对 |
| 长视频中途重置 | 阶段之间没有继承终态 | 把上一段终态写入下一段开始时 |
| 延长有接缝 | 边界和运动相位没锁 | 明确姿态、道具、机位、光线、声音与运动趋势 |
| 编辑改坏全片 | 任务写成重生成 | 唯一编辑母版 + 编辑范围 + 保持内容 |
| 台词漂移、错人张嘴 | VOICE PROFILE 被改写 / 说话人不清 | 固定 VOICE PROFILE，明确每句归属与口型条件 |
| 随机字幕/BGM | 声音政策缺失 | 明确字幕、BGM、环境声和动作音效政策 |
| 招牌/标签空白，场景像布景 | 资产图未生成画内文字 | 按文字清单重出资产图 |
| 资产图上错字、乱码、简繁混用 | 文字清单缺失或描述含糊 | 逐字写内容、字体和工艺，重出或局部修图 |
| 视频中文字漂移、变形 | 运镜掠过、遮挡、远景过小或物体在动 | 稳定文字所在物体、放缓运镜、加大占屏；特写仍漂移再编辑或后期兜底 |
| 同角度跳切 | 只生成孤立近景 | 补关系、过肩、动作中切换或不同景别 |
| 不可直拍内容生硬 | 试图用全景证明事件 | 改用画外声、局部、遮挡和人物反应 |
| 道具被手/身体挡过后消失、换样或出画再回来变了 | 模型没有物体记忆，遮挡区和画外每帧重画；小道具（占画高约 5% 以下）或与背景同色更易丢 | 写成整镜事实：“××始终在画面右下、不被手盖住、不出画”；每次提到都用同样的颜色+材质+一个特征；必须遮挡就把遮挡放在剪点（上一镜盖住、下一镜开场已是目标状态）或（项目允许首尾帧时）用首尾帧锁两端 |
| 动作变慢动作、结尾加速或发飘 | 动作时长和镜头时长不匹配；没写节奏时人物动作默认偏慢 | 给节奏一个数字或物理参照（“正常步速，约 0.5 秒一步”“匀速，不加速”）；按动作长度定这一镜秒数；轻微问题剪辑里变速，不重生成 |
| 手指畸形、多手、牙齿糊 | 手和牙小、高频、会自我遮挡，越动越漂；手占画高约 8% 以下最不稳 | 手保持合拢、贴身、握住大物件或出画；精细手部动作改成物件 Insert；偶发畸形可重抽 1–2 次 |

## 7. 通过标准

一个场次可通过，当且仅当：观众能说出本场发生了什么以及为何重要；关键人物的目标、注意力和情绪变化可见；空间与动作因果没有硬错误；大全景比例和人物—环境光关系可信；可辨认角色有具体任务且反应有因；关键道具与动作状态可追踪；重要信息得到足够反应时间；至少有一个关系或环境镜头支撑场面；P0 已清零；剩余 P1/P2 不会反向破坏已成立的表演和结构。
