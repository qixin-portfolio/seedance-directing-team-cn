# 输出契约

选择最贴近任务的一种结构，不为完整而输出空洞栏目。不得加入负责人、排期、交付频率或风险栏目。

## 输出复杂度等级

根据任务风险选择最低够用的交付等级，不因为 Skill 已加载就强制输出完整制片单：

| 等级 | 适用任务 | 输出 | 对应档位 |
|---|---|---|---|
| `L0` | 单一事实、局部改写、极简单镜头 | 结论或一句可执行指令 | 轻量 |
| `L1` | 普通单镜、低风险局部编辑 | 推荐设置 → 素材职责 → Compact Prompt → 一条主要风险 | 轻量 |
| `L2` | 多人、对白、连续性或中风险动作 | Shot Card → 素材职责 → 首帧提示词 → 视频 Prompt → 验收标准 | 标准 |
| `L3` | 高风险物理、复杂空间、多轮返修或正式生产 | Input Gate → 15-Block / 多镜头分镜 → Auditor → 返修/实验/Selects 记录 | 标准或导演组 |

参数由界面设置时，不伪装成 Prompt 正文。

## 1. 直接提示词（轻量）

推荐设置（版本、平台、模式；由界面设置的参数不写进正文）→ 素材职责（有素材时）→ 一份可直接粘贴的提示词 → 一条主要风险提醒。

## 2. 影视资产设计

资产编号；资产类型与用途；Canonical Descriptor / BASE IDENTITY；STATE OVERRIDE（有状态变化时）；**文字清单 TEXT SPEC**（场景/道具有画内文字时，见 [画内文字系统](../seedance/in-world-text.md)）；资产生图提示词（含文字内容、字体、工艺与位置）；必须烘焙的关键初始状态（没有则写“无”）；禁止烘焙的非必要临时信息；`VISUAL_APPROVED` 验收标准；压力测试计划；`PRODUCTION_APPROVED` 条件。

## 3. 镜头设计（标准）

- 镜头编号、所属段落、镜头目的、时长（已确认时）；
- 地点 / 人物 / 状态 / 道具资产；
- GOAL、TASK、DRAMATURGY、人物隐藏什么；
- 画面内容、人物动作、位置与朝向；可见非主要角色的任务（有时）；
- 摄影机位置、景别、焦距/FOV、摄影机运动、光源动机；
- 前景、中景、后景、光线与色彩；
- 复杂动作的力量来源、传力路径、承受对象反作用、稳定终态与必要 coverage；
- SCENE GEOGRAPHY LOCK / 空间锚点；
- INPUT GATE：READY / NOT READY / NOT REQUIRED，与每份素材的 Reference Role；
- 上一镜连续性、下一镜衔接、EDIT hook；
- 绝对禁止项；
- **首帧生图提示词**（需要时）；
- **图生视频提示词**（Compact / 15-Block / 多镜头分镜之一）；
- **验收标准**。

## 5. 六角色联合会诊（导演组）

```markdown
# 总导演总判断

# 总导演｜场次导演契约
- 一句导演命题 / 主要人物与观众视点 / 节拍与力量曲线 / Blocking states 与空间 / 关键电影时刻 / 不可改项

# 场记｜连续性基线
| 字段 | 上一镜出口 | 本镜入口 | 差异等级 | 修法 |

# 表演指导｜表演谱
| Beat | 刺激 | 目标/阻力 | 可演动作 | 注意对象 | 目光/呼吸/身体任务 | 台词动作 | 退出状态 |

# 镜内执行导演｜镜内生态表
| 角色/区域 | 任务 | 路径 | 注意对象 | 时点/延迟 | 强度 | 入/出画 | 与主戏关系 |

# 摄影指导｜摄影设计单
| 镜头 | 构图/机位 | 焦段/景深/焦点 | 承托/运镜/速度 | 光线/曝光/光学效果 | 接镜策略 |

# 提示词导演｜执行层预判
- Seedance 版本与平台 / 选用格式（Compact · 15-Block · 多镜头分镜 · 锚点段落式）/ 生成分组 / 素材职责表 / 平台限制与待核验参数

# 总导演与用户确认
# 提示词生成门：关闭 / 已授权
```

用户只点名一个角色时，只输出对应部分，不虚构其他角色意见。

## 6. 表演指导 / 摄影指导工作单

**表演**：表演总判断；人物既定情境、目标与阻力；角色表演档案引用（如已建立）；逐 Beat 表演谱（刺激、可演动作、注意对象、内部调整、目光/呼吸、身体/手部任务、台词动作/语气、反应延迟、退出状态、禁用套路）；给提示词导演的表演字段；去 AI 感检查；可观察验收条件。

**摄影**：摄影命题；构图与画面秩序；机位、角度与摄影机高度；焦段/FOV、景深与焦点；承托系统、运镜路径、触发与速度曲线（Seedance 2.0 每镜一个主要运镜）；光源动机、明暗比、色温与曝光；光学效果与时点；相邻镜头接缝；禁止项；可观察验收条件；器材组合（可选，仅设计参考，格式见 [摄影机与镜头选型](../director/camera-and-lens-system.md) 第 11 节）。

## 7. 多镜头分镜提示词

导演组档：用户未明确授权时不输出本节，只输出待确认项。轻量/标准档不设生成门。

使用 `assets/video-prompt-template.txt`。最终提示词放在一个 `text` 代码块中，不输出 JSON、伪 JSON 或代码块外的创作解释；没有确认的时长、画幅或技术参数不补默认值。素材标签用 `@图片N / @视频N / @音频N`，台词 `{}`、音效 `<>`、音乐 `()`、字幕 `【】`。

字数：总有效字符（去除空白）默认上限 5000，**但以当前平台实际输入上限为准**，平台更短时取平台值。前置资产与空间 ≤20%，逐镜内容 ≥65%，环境与风格约 15%。超限先删重复形容词、资产外观复述和全局重复，再压缩次要环境；不先删镜头动作、微表演、摄影路径或接镜状态；仍超限则拆成多条生成。

保存为文件后运行 `python3 scripts/validate_prompt_text.py <prompt.txt> [--max-chars N]`。

15-Block 单镜保存后运行 `python3 scripts/validate_15block.py <prompt.txt>`。

## 8. Prompt Auditor

```text
AUDIT：PASS / FAIL
阻断问题：
风险问题：
建议修改区块：
不得修改区块：
```

导演组档可在 FAIL 项后注明发现该问题的角色（如“摄影指导：镜头3 运镜无落点”）。

## 9. 提示词版本审稿

默认（导演组档）：

```markdown
# 提示词版本 / 授权依据 / 相对上一版变化
# Auditor 结论
# 角色意见（只列有问题的角色—镜头）
| 角色 | 镜头 | 观察/问题 | 具体建议 | 验收条件 |
# 用户反馈
# 未解决冲突
# 总导演裁决
# 下一版只改字段/区块
```

**严格审稿 / 逐镜会签**（用户要求时启用）：每个参与角色按镜头 1…N 逐条填写，六角色共 `6 × N` 行，没有问题写 `通过 / 没问题 / 保持`；`不适用` 必须写理由。

```markdown
| 角色 | 镜头 | 结论 | 观察/问题 | 具体建议 | 验收条件 |
|---|---:|---|---|---|---|
| 总导演 | 1 | 通过 | 没问题 | 保持 | …… |
```

保存后运行 `python3 scripts/validate_review_coverage.py <review.md> --shots N`（只让部分角色参与时加 `--roles 总导演,摄影指导`）。

```markdown
# 本场已成立的部分
# P0 必修
| 时间码 | 症状 | 根因 | 修法 | 验收条件 |
# P1 优化
# P2 后期项
```

```markdown
# 连续性差异
| 镜头/Take | 字段 | 上一出口 | 本镜入口 | 严重级 | 是否有意 | 修法 | 验收 |

| Take ID | 可用区间 | 过/保/修/废 | 短评 | 最小下一步 |

```

## 13. 输入设计与预演

高风险空间、倒置、悬空、复杂接触或受力镜头按 [输入设计与预演](../seedance/input-design-and-previs.md) 输出：`INPUT GATE：READY / NOT READY`；缺失的可读信息；需要新增的 Layout Plate / Shot State Plate / 关键帧 / 白模；每份素材的 `ROLE / ADOPT / IGNORE / FRAMING POLICY`；必须烘焙与禁止烘焙的内容；进入 Scene Map、Shot Card 和 Prompt Writer 的条件。

## 14. 物理动作设计

跳跃、坠落、拉扯、攀爬、撞击、材料失效或多个接触点按 [物理动作与因果 Coverage](../director/physical-action-design.md) 输出：动作母式；Physical Action Contract；关键相位与时间预算；施力主体与承受对象反作用；整体镜头或因果 Coverage 判断；需要的最少镜头与每镜可观察终态；受力方向、材料状态和时间进程的连续性锁定；验收标准。

## 15. 镜内生态与群演调度

专项任务按 [镜内生态](../director/in-frame-ecology.md) 输出：本镜注意中心 → 相关对象的任务/路径/触发/反应/可见性与出口 → 验收点。局部问题可用一段。只做设计或诊断时不强制输出完整镜头卡或生成 Prompt；未知人物和空间信息标待定，不擅自补剧情。

## 16. 控制变量实验与 Selects

**实验**：按 [生成实验与 Selects](generation-experiments-and-selects.md) 输出实验 ID、假设、模型与平台、Prompt 版本、参考素材集合、保持不变项、唯一测试变量、候选任务 ID、固定评分项、结论和下一步。不得输出多套没有实验目的的近似方案。

**Selects**：镜头编号、候选任务 ID / 文件、模型与 Prompt 版本、可用区间 IN–OUT、叙事功能、上下镜衔接、保留声音、区间外失败和 `CANDIDATE / SELECT_APPROVED / REJECTED` 状态。

**APPROVED**：只有用户明确说“锁定这个版本”“标记为 APPROVED”或“后续沿用这一版”时，才记录 `<镜头编号>_APPROVED`；“通过”“可以了”只记为候选接受。

## 17. 摄影指导与 Blender 预演

只要设计时交付摄影选择理由和 DP 载荷（[摄影指导](../director/cinematography-direction.md) 第 10 节）；需要搭建时追加 [摄影预演](../director/blender-camera-previs.md) 的场景/相机/时基、关键点表及可见验收标准。区分 PLANNED、RENDERED、REVIEWED；只链接实际生成文件。未给 Blender 场景或工具时可完成设计交接，不称已预演。只要预演时不强制附完整 Seedance Prompt；要转译时再输出素材职责与 Prompt，并明确尚未验证的生成遵循度。
