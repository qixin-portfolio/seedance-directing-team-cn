# 生成实验、候选与 Selects

生成不是一次提交后只判断成败。正式项目应区分随机重抽、结构返修、控制变量实验和剪辑素材筛选，并保留可追溯记录。

## 先选交付意图

- **FINAL SHOT MODE**：目标是整条生成结果作为一个最终镜头使用；优先减少动作密度和内部切镜。
- **MATERIAL SEQUENCE MODE**：目标是生成带明确硬切和多个动作节拍的源素材，后期只取其中稳定片段；必须提前说明预期 Select 和剪辑用途。

默认使用 FINAL SHOT MODE。只有动作蒙太奇、因果插入镜头、反应镜头或明确需要素材收割时使用 MATERIAL SEQUENCE MODE。不要把“只有几秒可用”事后包装成成功的素材策略。

## 四类生成动作

1. **随机重抽**：Prompt、参考素材和设置全部不变，只验证采样随机性。
2. **Workbench PATCH**：确认失败来源后，只修改一个区块或一个输入资产。
3. **控制变量实验**：预先定义假设，保持其余变量不变，比较两种输入或控制方案。
4. **模型 / 版本对照**：Prompt、参考素材、时长和可保持的平台设置尽量一致，只改变模型或版本。

模型对照若因平台限制无法保持分辨率、音频或其他设置一致，必须记录差异；评价时排除该差异影响，不把清晰度变化误判为动作遵循度提升。

## 实验矩阵

每轮只测试一个问题，例如：

- Layout Plate 直接作为首帧，还是 `LAYOUT_ONLY`；
- 复杂倒置状态只用文字，还是增加 Shot State Plate；
- 同一输入在 Seedance 2.0 与 2.5 的遵循差异；
- 全景完成整个因果动作，还是拆成局部受力镜头。

```text
EXP ID：
研究问题 / 假设：
源任务 ID（有时）：
模型与平台：
Prompt 版本：
参考素材集合：
时长与设置：
保持不变项：
唯一测试变量：
候选任务 ID：
结果与评分：
结论：
下一步：保持 / 有限重抽 / PATCH / 重建输入 / 拆镜 / 更换模式
```

不得在同一轮同时改模型、Prompt、参考图、时长和机位，然后声称已经找到原因。

## 候选评分

每项使用 0 / 1，必要时补一句证据：

| 维度 | 通过标准 |
|---|---|
| 身份 | 人脸、服装、角色和物件结构稳定 |
| 空间 | 上下前后、轴线、锚点和运动方向正确 |
| 动作 | 起始、触发、过程、反馈和终态顺序正确 |
| 物理 | 重量、重力、接触、惯性和反作用力可信 |
| 摄影 | 关键动作可见，景别和机位完成镜头任务 |
| 表演与声音 | 行为、眼神、口型、台词和声音归属正确 |
| 可剪性 | 存在明确、稳定、能承担叙事功能的时间段 |

评分只帮助比较，不替代导演判断。身份、空间或核心动作失败时，不因画面漂亮判定通过。

## Selects Manifest

候选结果进入剪辑前记录：

```text
镜头编号：
候选任务 ID / 文件：
模型、平台与 Prompt 版本：
可用区间 IN–OUT：
该区间的叙事功能：
承接上一镜：
交给下一镜：
保留的声音：
区间外失败：
状态：CANDIDATE / SELECT_APPROVED / REJECTED
```

系统可以推荐 Select，只有用户明确确认后才标记 `SELECT_APPROVED`。整条镜头或剪辑组合仍按现有规则由用户确认 `<镜头编号>_APPROVED`。

## 实验结束条件

- 假设已被足够清楚地支持或否定；
- 已找到满足核心验收项的候选或 Select；
- 同一结构性失败重复后已转入重建输入、拆镜或升级镜头设计；
- 不因已有投入继续无限生成。

本文件记录的是项目生产方法，不把单个公开案例或单次模型表现写成官方能力保证。
