# Prompt Auditor（生成前审计）

Auditor 只检查，不替 Writer 发明新创意。正式镜头写完后，在提交生成前执行一次。按任务只检查相关项，不为显示完整而逐条填写无关项。

## 问题级别

- **BLOCKER**：身份错、空间翻面、轴线破坏、台词归属错、素材职责冲突、关键动作因果断裂、错误版本能力或无法满足用户明确交付目标。出现任一项即 `AUDIT：FAIL`。
- **WARNING**：光影、声音、节奏、微表演或可剪性风险，不阻止生成，但必须列出修复建议。
- **NOTE**：可在后期处理的混音、调色或轻微 AI 痕迹，不阻止生成。

## A. 输入与素材

1. **Input Gate**：高风险空间或物理镜头是否已达到 `INPUT_READY`；困难初始状态是否错误地只靠文字硬压（见 [输入设计](../seedance/input-design-and-previs.md)）。
2. **Reference Role**：每份视觉输入是否声明 Role、采用内容、忽略内容和 framing policy。
3. **参考构图泄漏**：`LAYOUT_ONLY / STATE_ONLY / LOOK_ONLY` 是否可能被误当首帧；需要时是否写明 `REFERENCE ONLY, NOT A START FRAME`。场景 Plate 是否控制 geometry / material / light，却无意夺走最终 framing。
4. **素材职责冲突**：身份、服装、动作、摄影机、场景、时间、声音、风格是否有两个主控制源；`CAMERA_PREVIS` 与首尾图或文字冲突属 BLOCKER，先修输入。
5. **素材标签**：是否有旧版本 / stale tag、错误编号、未加载资产；是否误用 `@image1` 等英文标签；`@图片N` 是否直接接动词或方位词。
6. **版本/平台**：2.0 是否一镜一运镜；是否把 2.5 功能写给 2.0；平台参数是否误写进正文；字数是否超平台上限。
7. **空首帧**：镜头需要立刻开始时，首帧是否已有正确人物、道具和 blocking。
   **锚点误用**：分镜图是否被当成首帧/尾帧却没有接帧、延长或精确复现的理由（默认应为 `VISUAL_ANCHOR`）；锚点是否贴着 0 秒或结尾（各留约 1.5 秒）；两锚点之间是否有可见物理过程，还是会“直接变形”；每个锚点段是否写了抵达方式、文字复述和离开理由；是否有【结束状态】作为下一片段接口。

## B. 空间与动作

8. **空间地理**：Scene Map、固定锚点、画面左右与人物方向是否一致；近景是否继承 master 的位置和摄影机侧。
9. **轴线**：摄影机是否无意跨越 180° 线；已声明且过渡可读的有意越轴不误报。
10. **尺度契约**：大全景的人物、门、车和建筑比例能否通过现实测试。
11. **动作**：开始状态、触发、过程、反馈、终态是否完整，是否一段塞入过多状态变化。
12. **物理因果**：力量来源、接触点、传力路径和主要阻力是否属于同一条因果链；承受对象是否按质量、材料和固定方式反应；动作结束后是否有回弹、摆荡衰减、压缩恢复或静止（见 [物理动作](../director/physical-action-design.md)）。
13. **因果 Coverage**：全景无法同时看清多个接触点时，是否应拆成最少 Insert；拆镜后受力方向、材料状态和时间进程是否连续。
14. **道具与累积状态**：关键道具的数量、归属、开合、损坏和离场是否一致；消耗、脏污、湿润等状态是否无剧情原因重置，下一镜是否接续实际采用素材的出口。

## C. 表演、群戏与声音

15. **视觉前因**：台词评价的变化是否已有可见前因。
16. **表演链**：是否是目标—策略—可见泄漏—换招，而非抽象情绪；反应是否晚于刺激；身体联动与接触重量是否合理。
17. **微表情时间轴**：长特写是否有基线、触发、释放和余韵；高强度反应是否在触发前提前发生。
18. **说话者/听者双轨与台词时长**：触发词、停顿、听者反应和画外台词是否保持声源、视线与空间连续；对白能否在预算中自然说完；画外台词是否误要求口型。
19. **镜内生态**：可辨认的次要人物是否有任务与有因反应；路线是否遮挡关键表演或提前揭示信息；静态占位是否被误作动作主源；跨镜持物与位置是否接续。允许有意静止或有因同步，按实际叙事影响评级（见 [镜内生态](../director/in-frame-ecology.md)）。
20. **声音**：说话人、VOICE PROFILE、BGM、环境声和音效归属是否冲突；承担叙事功能的环境事件是否与画面共用触发和持续状态，切镜是否无故重启事件。

## D. 摄影、光线与画面

21. **摄影动机**：运镜有无触发、信息显露点和落点；复合运动是否服务一个摄影意图；光学效果是否超过一至两项。
22. **声音与光影基线**：是否有可信世界光源、2–4 个具体声音锚点和结尾衰减；人物是否响应环境光区，有无无来源美颜光；光影变化是否有画面内原因。
23. **器材与光学**：是否只写器材名而无可见结果；是否写了“2× Anamorphic = 焦距×2”；S35 镜头是否被默认配全画幅；动作或多人镜头是否用了极浅景深（T1.4 级）；是否把帧率写成参数而非运动质感；器材名、光学效果和后期风格是否相容（数字摄影叠加明确的胶片后期不视为矛盾）。
24. **画内文字**：场景/道具本应有文字时资产图是否已带上；A 级文字是否逐字写出并要求保持；文字区域是否被快速运镜、遮挡或远景缩小置于高漂移风险（见 [画内文字](../seedance/in-world-text.md)）。
25. **年代 / 世界规则**：高风险现代元素、未授权 Logo、错误年代文字是否破坏 World Bible。

## E. 结构与交付

26. **区块矛盾**：例如 CAMERA 写固定机位，ACTION 又要求摄影机跟随；门被要求“始终关闭”又在时间线上打开。
27. **Delivery Intent 与时间完整性**：FINAL SHOT 是否动作过密；MATERIAL SEQUENCE 是否预先定义节拍、剪辑点和预期 Select。声明的镜头数与逐镜清单是否一致、镜头区间是否连续覆盖总时长、实时与慢动作区间是否明确；不把同时发生的人物、环境与声音事件误报为镜头区间重叠。
28. **压缩结果**：压缩是否只删重复和装饰，未损失素材职责、动作因果、关键台词、终态与结尾余韵。

## 摄影预演专项（仅有相应任务时）

检查摄影机运动动机、揭示时点、复合轨迹中间段、FOV 口径、焦点与世界光源连续性。未经观看的预演只能标 PLANNED / RENDERED，不能宣称摄影验收或生成遵循度已通过（见 [Blender 摄影预演](../director/blender-camera-previs.md)）。

## 输出

```text
AUDIT：PASS / FAIL
INPUT GATE：READY / NOT READY / NOT REQUIRED
BLOCKER：
WARNING：
NOTE：
建议修改区块：
不得修改区块：
```

FAIL 时只把问题交给 [Workbench](prompt-workbench.md)，不重写整条 Prompt。导演组档可注明是哪个角色视角发现的问题（如“摄影指导：镜头3 运镜无落点”）。
