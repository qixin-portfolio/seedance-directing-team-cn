## 1. 职责边界

摄影指导把总导演的叙事意图、表演调度和空间关系转译成可见的摄影系统。负责机位、角度、景别、构图、焦段、景深、焦点、摄影机运动、承托方式、速度曲线、光线、曝光、色温与光学质感。

摄影指导不改写场次目的、人物关系或表演动作；不因为技术炫耀制造无动机运镜。若总导演要求某种摄影风格，应把它拆成可观察特征，不只写摄影师姓名、影片名或“高级感”。

## 2. 摄影设计顺序

1. 读取总导演的场次命题、重点、主观人物和 blocking states。
2. 读取空间 master、轴线、摄影机可进入区域和连续性入口/出口。
3. 先确定观众与人物的距离，再确定景别和焦段。
4. 决定画面秩序：对称/失衡、稳定/躁动、观察/卷入、深空间/压缩空间。
5. 决定摄影机是否运动；若运动，写清叙事动机、承托、路径、速度曲线和停止点。
6. 设计焦点、景深、光线与曝光，使其支持调度和表演。
7. 检查相邻镜头的方向、动势、景别跨度、运动接缝和光线连续性。

每个技术选择都回答两个问题：它保护什么叙事信息？观众能看见什么结果？

## 3. 构图与镜头组

### 构图变量

- 摄影机高度：地面、腰部、胸口、眼平、略高、顶视；
- 俯仰与水平：平视、俯视、仰视、荷兰角；
- 主体位置：中心、三分区、边缘压迫、负空间方向；
- 画面秩序：严格对称、近似对称、框中框、几何线条、动态斜线；
- 空间层次：前景遮挡、中景关系、后景事件、深焦或层次压缩；
- 视点关系：客观观察、人物主观、过肩、贴身伴随、监视或窥视。

“工整、对称”需要写明中轴、左右重量、透视消失点和主体偏离规则。“张力”需要落实为距离、角度、遮挡、边缘压力、运动速度或焦点变化。

镜头组要共同完成场次，不把每个镜头都设计成独立炫技镜头。明确建立、关系、动作、反应、细节和接缝各自功能。

## 4. 焦段、光圈与焦点

焦段先服务空间感，再服务面部：

- 广角可强化前后距离、贴近感和运动速度，但需检查边缘变形；
- 标准焦段保持自然关系，适合中景和稳定对话；
- 长焦压缩空间、隔离人物、制造观察感，但不能掩盖必要地理；
- 微距用于纹理和关键物件，不替代叙事建立。

不要把焦段数字当装饰。只有用户、项目规范或目标模型需要时才写具体毫米数；否则写等效视觉结果。

需要收敛到具体摄影机、镜头家族、焦距和 T-stop 组合时，在本节设计完成后查 [摄影机与镜头选型](camera-and-lens-system.md)：焦距/光圈速记、镜头性格六类、画幅兼容和 14 个组合预设。器材选型是最后一步，不倒过来用器材决定镜头。

光圈与景深必须匹配调度：多人关系镜头不能为了“电影感”把关键人物虚掉；极浅景深需要明确焦点对象、焦点是否移动、何时移动。写 rack focus 时说明起点、触发、终点和叙事作用；不需要变焦或拉焦时明确锁焦。

## 5. 运镜与承托系统

先问静止是否更有力量，再选择：

| 系统 | 适用结果 | 必须写清 |
|---|---|---|
| 锁定机位 | 克制、观察、几何秩序 | 主体如何在固定画框内调度 |
| 三脚架摇移 | 观察空间或跟随有限动作 | 摇移方向、触发点、停止构图 |
| 轨道/滑轨/Dolly | 稳定推进、揭示、关系距离变化 | 路径、总距离、速度曲线、终点 |
| 稳定器/Steadicam | 流动伴随、穿越空间 | 跟随对象、距离、转向和避障 |
| 肩扛/手持 | 身体在场、压迫、不确定 | 抖动幅度、频率、是否保持可读性 |
| Moco | 精确重复、复杂合成、机械节奏 | 可复现路径、节点、速度和同步事件 |
| FPV | 高速穿越、强主观、空间冲击 | 飞行路线、转弯半径、贴近物和安全可读性 |
| 摇臂/升降/航拍 | 尺度揭示、权力或地理变化 | 起止高度、弧线、揭示信息 |

夸张运镜必须有清晰可读的起点、高潮和落点。镜头连贯性来自运动方向、主体速度、视线、构图重心和剪接点的共同延续，不只是“流畅运镜”。

## 6. 时间、快门与运动质感

- 快慢速设计写清正常速度、加速/减速触发点、持续阶段和回到正常速度的时机。
- 速度变化服务感知：突出冲击、延长决定、压缩路程或制造失衡；不要无动机 speed ramp。
- 帧率、快门角和运动模糊属于 O 类参数。只有目标模型或后期流程需要时写数值，并同时描述期望的运动清晰度/拖影结果。
- Whip pan、快速旋转、FPV 和长路径运镜先保证空间可读与主体识别，再追求速度。

## 7. 光线与光学现象

先写光源动机，再写效果：来源、方向、软硬、明暗比、色温、人物经过的光区和曝光变化。项目可以选择 practicals-only、自然光、棚拍塑形或混合策略；不得把某一种灯光方法设为所有项目的永久规则。

可选光学语言包括：

- 逆光轮廓、侧逆光、顶光、负补光、环境反射；
- 受控过曝、剪影、暗部保留或高反差；
- 焦外光斑的形状、大小、颜色和位置；
- 变形宽银幕拉丝、镜头 flare、halation、bloom；
- 前景虚焦、呼吸效应、rack focus、短暂失焦再回焦；
- 运动模糊、污渍、雨滴、玻璃反射等有动机的镜前质感。

每种效果说明来源与时点。不要同时堆满 flare、拉丝、雾、bloom、浅景深和手持；选择一至两项主导特征。

## 8. 摄影连续性与审稿

摄影设计单至少包含：

```markdown
# 摄影命题
# 构图与画面秩序
# 机位、角度与摄影机高度
# 焦段/景深/焦点策略
# 承托系统、运镜路径与速度曲线
# 光源动机、明暗比、色温与曝光
# 光学效果与使用时点
# 相邻镜头的方向、动势、焦点和光线接缝
# 禁止项
# 可观察验收条件
```

审提示词时逐镜检查：是否体现摄影命题；焦段与空间是否一致；运镜有无动机和落点；快慢速是否有触发；光线是否有来源；光学效果是否过载；相邻镜头能否连贯；技术数字是否真的必要。问题只反馈到摄影字段，不擅自重写表演或剧情。

## 9. 落到 Seedance

- 焦段写成可见结果：FOV、主体占屏比例、透视压缩、景深与前景关系，毫米数只作辅助，见 [光学与 FOV](../seedance/optics-fov.md)。
- **每镜一个主要摄影意图**。“一个意图”不等于只允许一个变换通道：沿弧线移动并摇摄保持人物、升降同时俯仰揭示地形，都可以是一个连贯运动（见第 10 节）。
- **Seedance 2.0 额外从严：一镜一运镜**，不在同一镜头叠加推、拉、摇、移；需要复合运动时拆镜、在切点换运动，或用 `CAMERA_PREVIS` 参考视频作为路径主源并先小样测试。
- Seedance 2.5 可用阶段或时间戳描述运动触发点，可写协同复合运动，但每阶段只服务一个摄影意图。
- 精确复杂运镜优先用参考视频或粗粒度白模作为摄影机路径的唯一主控制源，文字只补空间与落点，见 [关键帧分镜白模](../seedance/keyframes-storyboards-white-model.md)。
- 光学效果（flare、拉丝、halation 等）写来源与时点；模型对其遵循度属 O 类，先小样测试。
- 器材组合（摄影机 + 镜头 + 焦距 + 光圈）只作设计依据；写进提示词时翻译为可见结果，器材名最多作弱风格提示，见 [摄影机与镜头选型](camera-and-lens-system.md) 第 9 节。帧率与快门写成运动质感，不写成参数。
- 摄影设计单编入提示词时：构图/焦段→“机位”或 OPTICS；运镜→“摄影机运动/位置”或 CAMERA；光源→“背景/风格”或 LIGHTING。

## 10. 观看关系、运动触发与摄影决策载荷（来自 Seedance V2.3）

### 先决定观众如何获得信息

读当前 GOAL、DRAMATURGY、人物 blocking、场景地理和已确认视觉风格，再回答：观众跟谁看、此刻应看见什么、暂时不看见什么、何时改变认识。缺少剧情时不发明人物动机；可以给标注为“摄影提案”的选择理由。

- 机位决定观看关系：在人物身旁、隔着障碍观察、跟随其视线，或比人物先发现信息。
- 景别决定信息权重：动作是否需要看全身，关系是否需要同框，是否需要读脸。不要把“紧张”等同于一律推进特写。
- 高度、俯仰和人物距离分别决定从谁的高度看、看向哪里、离人有多近。拍坐着的人时，不用向下俯拍代替降低机位，除非俯视本身有目的。
- 焦距与机距联合选择：固定机位换焦距主要改变取景范围；为维持相同景别而改变机距才会改变前后景透视关系。

每颗镜头只写能说明选择的短理由，例如“门口先被前景挡住，人物回头时摄影机横移露出门外的人”。

### 设计运动的触发与结束

| 需要解决的画面问题 | 可考虑的摄影策略 | 需要检查的结果 |
|---|---|---|
| 信息尚未暴露 | 固定等待、横移越过遮挡、跟随视线摇摄 | 目标是否恰在剧情触发之后出现 |
| 观众要进入人物的决定 | 走近、缓慢推进或保持距离等待表演 | 占屏变化是否抢在表演前，结尾是否留得住 |
| 关系或环境改变理解 | 拉远、升高、侧移形成新同框 | 新信息是否可读，原主体是否仍有叙事位置 |
| 人物穿过空间 | 跟移、领拍、让人物走出固定画面 | 地理、视差、速度和人物视线是否连续 |
| 注意从一人交给另一人 | 重构图、跟随动作、转焦或切镜 | 观众能否看见注意转移的原因 |

这些是可选策略，不是镜头动作与情绪的一一对应公式。每次运动写明：起动触发 → 主体与摄影机相对变化 → 信息显露点 → 减速/停留 → 剪辑出口。固定镜头也写其等待的事件。

区分位置轨迹、朝向、焦距、焦点；只有各自服务不同叙事事件且在时长内无法读清时才建议拆镜。不要因为有 Blender 就默认安排复杂运动。

### 光线与焦点补充

- 光源落在世界地图上：窗侧、门外、桌灯，而不是永远“画面左光”。换机位后重新判断亮面和阴影的屏幕位置，不让主光跟摄影机旋转。
- 运动前中后检查眼睛、脸、手和关键道具的可读性；合理经过阴影可以保留，不自动均匀提亮全程。
- 白模运动预演默认不证明最终材质、肤色或曝光；需要评估布光时另做灯光测试。
- 转焦要让前后两个信息都有足够可读时间；深景深也是有效选择。

### 组镜

正反打可匹配，也可为权力、主观视角或信息变化有意不对称；说明理由，不要求焦段和高度机械相同。有意越轴时预演连续越轴过程或建立新方向的镜头；大幅机位运动若始终看不清关键行为，先改 blocking、路径或景别，再考虑补镜。

### 摄影决策载荷

普通镜头用一段 CAMERA 加 LIGHTING 即可。复杂摄影/白模任务在 Shot Card 下输出：

```text
DP INTENT：观看视角 / 必须看见与暂时隐藏的信息
CAMERA：景别变化、机高、距离、轴线侧、焦距和视场口径
COMPOSITION：起点 / 信息转折 / 终点的主体比例与空间层次
MOTION：动机、触发、路径、朝向、速度节奏、结束条件
FOCUS：关注对象与转移时机（需要时）
LIGHT：世界光源、明暗注意层级、运动中光线变化
EDIT：前后镜衔接及停留需求
VERIFY：本镜最重要的可见验收点
```

需要 Blender 搭建、渲染预演或把轨迹交给 Seedance 时，转 [Blender 摄影预演](blender-camera-previs.md)。已有已确认轨迹时以审查和局部修正为主，不为套用摄影套路重做。交给 `cinedance-v4`（Codex 中可用时）只编译这些已决定内容，不重新选择焦段、轨迹或视觉风格。

参考：[everything-ai-filmmaking 摄影模块](https://github.com/MRCalderon3D/everything-ai-filmmaking/blob/main/skills/cinematography/SKILL.md)提供了镜头选择与戏剧功能连接的思路；本节未采用其正反打参数必须相同等绝对限制。摄影判断属于创作提案，不是 Seedance 官方规范。
