## 1. 在本 Skill 中的位置

摄影指导先完成 [摄影设计](cinematography-direction.md)：观众距离、构图秩序、运动动机、光源。**器材选型是最后一步**，用来把已经确定的视觉意图收敛到一个具体、自洽的“摄影机 + 镜头 + 焦距 + 光圈”组合。

- 本文件的组合与默认值是**设计讨论阶段的推荐起点**，不是提示词默认值。未经摄影指导或用户确认，不自动写入提示词。
- 写入 Seedance 提示词时，以**可见结果**为主（见第 9 节和 [光学与 FOV](../seedance/optics-fov.md)），器材名最多作为弱风格提示。
- 焦距的空间与透视原理见 [光学与 FOV](../seedance/optics-fov.md)；本文件只给选型规则。

## 2. 判断链与最终优先级

**叙事目的 → 摄影机底色 → 镜头性格 → 焦距空间 → 光圈景深 → 运动方式 → 最终光学效果**

- 摄影机决定基础成像与画幅倾向；
- 镜头决定画面的主要光学性格；
- 焦距决定人物与空间的关系；
- 光圈决定景深与焦点容错；
- 灯光、调度、构图和调色完成最终电影风格。

最终优先级：**叙事目的 > 空间关系 > 摄影机位置 > 镜头性格 > 焦距 > 光圈 > 器材品牌**。

## 3. 强制原则

1. 不为了“电影感”默认使用 85mm + T1.4；T1.4 是风格工具，不是电影感默认值。
2. 不把所有人物镜头都做成强背景虚化；人物镜头优先保证脸型自然、身份稳定、环境关系合理。
3. 动作镜头优先保证空间关系、重量感和焦点稳定；环境镜头保留足够景深和空间信息。
4. 广角用于空间，不等于“越广越宏大”；长焦用于压缩，不等于“越长越高级”。
5. 电影镜头优先用 T-stop 表示光圈。
6. 必须检查摄影机画幅与镜头像场覆盖是否兼容。
7. **2× Anamorphic 表示水平光学压缩，不等于焦距乘 2。**
8. 老镜头和实验镜头只在叙事确有需要时使用。
9. 器材名称中英并写（如“阿莱 ALEXA 35 / ARRI ALEXA 35”），其余说明用中文。
10. AI 视频优先稳定、可读、可持续的摄影参数，不为单帧美感牺牲运动连续性。

## 6. 焦距与光圈速记

### 焦距

| 焦段 | 特点 | 定位 | 适合 / 注意 |
|---|---|---|---|
| 14–18mm | 极强透视、近大远小、人脸易变形 | 极端空间 | 巨型建筑、超现实空间、极端压迫；少用于人物近景 |
| 21–24mm | 广阔、透视较强但可控 | 空间焦段 | 建筑、战场、宫殿、大空间、环境人物 |
| 28–29mm | 沉浸、动态自然、比 24mm 克制 | 运动叙事 | 跟拍、一镜到底、稳定器、战斗调度 |
| 32–35mm | 人物自然、空间清晰 | 万能叙事 | 剧情、人物互动、动作 |
| 40mm | 比 35mm 克制、比 50mm 有空间 | 高级自然主义 | 环境人物、克制商业、现代剧情 |
| 50mm | 透视自然、主体开始突出 | 标准人物 | 人物中景、对话、产品 |
| 65–75mm | 压缩增强、人脸自然、背景分离 | 情绪与肖像 | 半身、人像、汽车、时尚 |
| 85–100mm | 主体分离强、压缩明显 | 广告与特写 | 特写、汽车英雄镜头、奢侈品；不因“高级”默认使用 |
| 135mm+ | 强压缩、远摄观察感 | 压缩与观察 | 城市人物、汽车运动、远距离观察、抽象建筑 |

记忆：**24 = 空间，35 = 剧情，50 = 人物，75 = 情绪，100 = 隔离，135+ = 压缩。**

### 光圈（T-stop）

| 光圈 | 特点 | 定位 | 限制 |
|---|---|---|---|
| T1.3–T1.5 | 极浅景深、强分离、夜景进光 | 梦境、夜戏、情绪特写 | 动作和多人慎用；不作电影感默认 |
| T1.8–T2 | 明显浅景深、仍有焦点容错 | 人物电影感 | |
| T2.8 | 景深与分离平衡、环境可读 | 万能平衡值，AI 视频首选起点 | |
| T4 | 环境清晰、动作容错大 | 环境与动作优先 | |
| T5.6–T11 | 深景深、前后景完整、需更多光 | 大场景、产品、微距、VFX | |

### 选型决策

1. **空间还是人物**：空间优先 21–35mm；人物优先 35–85mm。
2. **有无明显运动**（跟拍、战斗、跑动、一镜到底、机械运动）：优先 28–40mm + T2.8–T4。
3. **要不要明显镜头性格**：不要 → Signature / Leitz Prime / Ultra Prime；温暖人物 → Cooke / Summilux-C；复古 → K-35 / HUGO；宽银幕 → C-Series / V-Lite；实验 → Petzval / Helios / Lensbaby；微观 → Laowa Probe。
4. **检查画幅兼容**（第 7 节）。
5. **定焦距**：根据叙事，不根据“高级感”。
6. **定光圈**：默认起点 T2.8；人物静态可开到 T1.8–T2；动作和环境收到 T4。

## 7. 画幅兼容与 Anamorphic 规则

**画幅兼容：**

- Super 35 镜头（如 Ultra Prime）优先配 ALEXA 35、其他 S35 机身或 VENICE 的 S35 模式；不默认覆盖全画幅传感器。
- 大画幅镜头（Signature Prime、Leitz Prime、Cooke S8/i）配 Mini LF、VENICE 2、大画幅 RED 等。
- 老全画幅镜头（Helios 44、Petzval）上 16mm：只截取中央像场，外围旋焦、暗角和边缘性格可能被裁掉，视角明显变窄——只作实验组合。

**Anamorphic：**

1. 2× 是水平压缩比例，不是焦距倍率；不得写“50mm 2× = 100mm 等效”。
2. 需要对应传感器模式和最终 De-squeeze。
3. 画面特征：椭圆焦外、水平 flare、边缘形变、呼吸、水平视野扩展。
4. 不要为了“电影感”给所有科幻镜头加 anamorphic flare；Clean Sci-Fi 优先球面镜头，需要明显光学性格时再切换。

## 9. 落到 AI 生图与 Seedance

> **用户偏好（2026-11-03）**：本用户是 DP，要求器材名写进提示词：风格行写摄影机与镜头系列，每个机位写实际焦段和 T 档（如“Cooke S4/i 40mm，T2.8”），焦段取该系列实有规格；可见结果照旧跟在后面。对本用户，下文“器材名可选、弱提示”的默认让位于此。

### 先写可见结果，器材名最后

生成模型执行的是画面描述，不是器材参数。器材组合必须翻译成可见结果：

| 选型 | 写进提示词的可见结果 |
|---|---|
| 焦距 | 等效视野/FOV、主体占画面比例、透视强弱、背景压缩程度 |
| 光圈 | 景深范围：谁清晰、背景虚化到什么程度、空间锚点是否仍可辨 |
| 镜头性格 | 反差、高光晕染、焦外形状（圆/椭圆/旋转）、flare 的来源与方向、边缘柔化 |
| 画幅 | 空间纵深感、主体与环境的分离方式；宽银幕比例由平台画幅设置决定 |
| 胶片 | 颗粒粗细、高光滚降、色彩倾向 |

器材名可以作为**弱风格提示**附在后面（如“画面质感接近 ARRI Signature Prime 的干净通透”），但：

- Seedance 对器材品牌名是否有稳定响应**尚未验证**，属 O 类，先小样测试再决定是否保留；
- 不得只写器材名而不写可见结果；
- 素材已经确定外观和光线时，不重复堆器材名。

### 帧率与快门：写运动质感，不写参数

Seedance 的输出帧率、时长和分辨率由平台设置决定，不由提示词控制。把帧率/快门选型翻译成运动描述：

- 24fps + 180° 快门 → “自然运动模糊，正常速度”；
- 48–60fps 轻度慢放 → “轻微慢动作，布料和头发运动清晰”；
- 96–120fps+ 高速 → “明显慢动作，碎片/液体/火花轨迹清晰可见”，并写清慢动作的开始与结束触发点；
- 不写“某摄影机永远可以在所有格式下 120fps”，也不把 120fps 写进提示词当参数。

### AI 视频优先级与推荐起点

**运动可读性 > 空间关系 > 焦点稳定 > 单帧美感**

推荐起点（非默认值）：28–40mm 等效视野、T2.8–T4 对应的中等景深、正常速度运动模糊；不默认 T1.4，不默认 85mm，动作镜头避免超浅景深。Seedance 2.0 下仍是一镜一运镜。

### AI 生图（资产与首帧）

资产图可以适度强化镜头家族、焦距、光圈和光学性格，但同时写清摄影机位置、构图、主体距离、光线、景深和前后景关系。影视资产图（人物卡、场景 Plate）优先中性、可读，不加强烈镜头性格，见 [资产生产](../seedance/asset-production-system.md)。

## 10. 禁止默认化

不要自动套用：所有人物 = 85mm；所有电影感 = T1.4；所有科幻 = 蓝色 anamorphic flare；所有商业 = 极浅景深；所有复古 = 加颗粒；所有大场景 = 14mm；所有汽车 = 长焦虚化；所有夜景 = 无补光纯高 ISO；所有运动 = 120fps；所有胶片 = 暖黄色。

电影感优先来自 **构图 + 摄影机位置 + 镜头性格 + 焦距 + 灯光 + 调度 + 景深 + 色彩 + 剪辑**，而不是单一器材参数。

## 11. 选型输出格式

用户要求摄影器材方案时：

```markdown
**视觉目标：** 一句话说明镜头承担的叙事任务
**摄影机：** 中文名 / English Name
**镜头：** 中文名 / English Name
**画幅 / 模式：** Super 35 / Full Frame / Large Format / Anamorphic 模式
**焦距：** XXmm
**光圈：** T X.X
**运动质感：** 正常速度 / 轻度慢动作 / 高速慢动作（真实拍摄时注明 fps 与快门角）
**适用原因：** 1–3 句
**使用要点：** 只写真正影响执行的 2–4 项
**风险 / 禁忌：** 画幅覆盖、焦点、畸变、过浅景深、过度 flare 等
**提示词可见结果：** 视野与占屏、景深、焦外与 flare、反差与质感、运动模糊（器材名可选附后）
```
