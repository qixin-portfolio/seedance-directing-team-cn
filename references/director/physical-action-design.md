# 物理动作设计与因果 Coverage

复杂动作先设计因果链，再写时间轴。不要只描述动作主体；同时写力量从哪里产生、经过什么接触传递、哪个对象承受、如何反馈以及最终怎样稳定。

## Physical Action Contract

```text
动作主体：
力量来源与方向：
质量、速度与材料：
接触点：
传力路径：
主要阻力：
承受对象及反作用：
可见次生后果：
最终稳定状态：
```

基础公式：

`力量来源 → 接触 → 传力路径 → 阻力或失效 → 承受对象反应 → 回弹 / 衰减 / 稳定终态`

一个物理原因配两三个可见后果，通常比三个互不相关的动作更可信。

## 动作相位母式

只选择与当前镜头有关的相位，不机械塞入全部阶段。

### 蓄力、跳跃与落地

`压缩蓄力 → 释放离地 → 上升 → 顶点 → 下落 → 撞击压缩 → 回弹稳定`

必须看见离地前的加载、真实弧线、落地接触和承受冲击后的反馈。被蹬离的地面、载具或另一主体也要产生反作用。

### 张力、滑脱与拉住

`张力建立 → 锚点或材料滑脱 → 短暂下坠 → 突然拉住 → 回弹 → 摆荡衰减`

区分“即将掉落但仍被拉住”和“完全断裂自由落体”。钢缆、锚点、缠绕部位与悬挂主体必须属于同一条受力链。

### 阻力、松动与开启

`接触把手 → 初次用力但不动 → 增加全身力量 → 材料开始松动 → 突然让位 → 身体和物件过冲 → 稳定`

舱门、铰链、抽屉或卡住的机械不能无阻力自动打开。材料让位时补声音、碎屑、形变或光线变化等次生后果。

### 抓握、攀爬与重量转移

`试探落点 → 建立抓握 → 转移部分重量 → 原支点释放 → 身体摆动或下沉 → 新支点承重 → 恢复并寻找下一锚点`

每一阶段明确哪只手、脚或支点承重。疲劳通过握力、呼吸、滑动、停顿和重新抓握表现，不用“艰难地”代替动作。

### 撞击、抛掷与停止

`加速 → 接触 → 形变或动量传递 → 承受对象位移 → 主体 follow-through → 碎屑或材料反馈 → 减速停止`

撞击不能只让施力主体表演；承受对象必须按质量、固定方式和材料产生对应反应。

## 相位预算

- 4–8 秒短镜头优先保留 3–5 个关键相位。
- 准备动作过长时，让首帧处于动作将起或已加载状态。
- 每个相位只有一个主要状态变化，并以可观察终态结束。
- 关键物理反馈至少留出一个可读瞬间；不要让摄影机在接触点发生时转走。
- 动作完成后必须有回弹、摆荡、过冲、压缩恢复或静止等 endpoint，避免无休止运动。

## 因果 Coverage

当一个全景同时包含复杂空间、多个接触点和材料失效而连续失败时，不继续加长 Prompt。沿同一受力链选择必要镜头：

1. **Geography Shot**：说明主体、承受对象和空间方向。
2. **Force Source Insert**：手、脚、液压、绞盘、发动机或风从哪里施力。
3. **Load Path Insert**：钢缆、关节、握点、支架或材料如何传递力量。
4. **Failure Point Insert**：锚点滑脱、混凝土开裂、铰链变形或抓握打滑。
5. **Result / Reaction Shot**：主体和承受对象如何回弹、位移、摆荡或稳定。

不要求每场都生成五个镜头。选择观众理解因果所需的最少 coverage，并保持同一身份、场景、受力方向、材料状态和时间进程。

## 整体动作还是拆镜

- 空间单一、接触点少、动作链短：优先整体镜头。
- 有两个以上关键接触点、结构失效或全景连续失败：优先因果 Coverage。
- 整体动作基本正确、只有一个局部不可读：保留主体镜头，补一个 Insert。
- 只有局部特写但观众不知道谁在何处：先补 Geography Shot，不靠对白解释空间。
